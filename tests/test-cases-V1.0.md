## 二、用户路径总览（12 条主路径）

```
路径 A：首次使用 ─────────────────────────────────────────────────────────
  Splash → Onboarding(3页引导) → Register(手机号+OTP+年级+家长同意) → Home

路径 B：错题录入（核心路径）───────────────────────────────────────────────
  Home → 底部[+] → AddQuestion(拍照/相册) → 裁剪 → OCR识别 → 确认信息
       → 选错因 → 选知识点 → 保存 → Toast提示 → 自动加入复习计划

路径 C：每日复习（核心路径）───────────────────────────────────────────────
  Home → [今日待复习 N 道] → Review(卡片正面) → [显示答案] → 卡片翻转
       → 自评[完全掌握/部分记得/不会] → 下一题 → ... → 全部完成
       → ReviewReport(统计) → 消灭动画(如有) → Home

路径 D：错题本浏览与筛选 ─────────────────────────────────────────────────
  底部Tab[错题本] → QuestionList(全部/按状态/按错因/按知识点/按时间/搜索)
       → 点击某题 → QuestionDetail(全部字段+复习历史时间线+进度条)

路径 E：错题编辑与删除 ──────────────────────────────────────────────────
  QuestionDetail → [编辑] → 修改各字段 → 自动保存
                    [删除] → 确认弹窗 → 软删除 → 移入回收站

路径 F：回收站管理 ──────────────────────────────────────────────────────
  Profile → [回收站] → RecycleBin(列表+剩余天数)
       → 逐条恢复 / 清空全部(二次确认)

路径 G：学情周报 ───────────────────────────────────────────────────────
  底部Tab[周报] → WeeklyReportList(历史周报列表)
       → 点击某周 → WeeklyReportDetail(统计+对比+成就+薄弱知识点)
       → [分享] → 生成长图 → 系统分享

路径 H：个人设置 ──────────────────────────────────────────────────────
  底部Tab[我的] → Profile
       → 修改昵称/头像/年级
       → 复习提醒设置(时间/开关)
       → 存储管理(已用/总量/清理)
       → 消灭动画开关
       → 每日复习上限
       → 主题切换
       → PDF导出
       → 退出登录
       → 注销账号(二次确认)

路径 I：复活检测 ──────────────────────────────────────────────────────
  Review → 复习列表末尾(带"复习巩固"标签) → 展示原题目
       → [还记得] → 递进间隔(30→60→90天) / 永久消灭
       → [忘记了] → 回到REVIEWING(count归零) + 鼓励文案

路径 J：离线录入 + 同步 ──────────────────────────────────────────────
  断网 → AddQuestion(拍照录入全流程) → 数据存本地SQLite
       → 首页显示 ⏳待同步 图标
       → 联网 → 自动上传(图片先传OSS→再传数据) → ✅已同步
       → 失败 → 最多3次指数退避(1s→2s→4s) → ❌同步失败(手动重试)

路径 K：PDF导出 ─────────────────────────────────────────────────────
  Profile → [PDF导出] → PdfExport(选时间范围: 本月/近3月/全部)
       → 预览 → [导出] → 客户端生成PDF(图片拼接)
       → 系统分享(Sheet/Intent)

路径 L：Token 过期刷新 ──────────────────────────────────────────────
  正常使用 → Access Token过期(30天) → 自动用 Refresh Token 换新
       → Refresh Token也过期(90天) → 引导重新登录 → 不丢本地数据
```
