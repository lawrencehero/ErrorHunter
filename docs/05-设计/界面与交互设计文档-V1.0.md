## 1. 设计概述

### 1.1 设计理念与原则

> **用户的第一感受是什么？** —— 这是我在每个设计决策前必问的问题。

错题猎手的用户是**小学3年级到初中的学生**，他们打开APP的第一感受应该是：**"这个工具不吓人、不无聊、用起来有成就感"**，而不是"又一个学习负担"。

| # | 设计原则 | 释义 | 反面案例 |
|---|---------|------|---------|
| 1 | **轻量感 > 功能堆砌** | 每屏只传递一个核心任务，不让信息过载 | 首页塞满10+模块，小学生不知从何点起 |
| 2 | **成就感 > 压迫感** | 强调"已消灭N道"而非"还有N道没做"；文案用鼓励式 | "你还有50道题没复习！" → ❌ |
| 3 | **系统多做 > 用户少做** | AI推荐错因/知识点，用户只需确认或微调 | 让用户从100个知识点里手动搜索选择 |
| 4 | **一致可预期** | 相同操作产生相同反馈，减少认知负荷 | 不同页面的"保存"按钮位置忽左忽右 |
| 5 | **容错友好** | 任何误操作都可撤回，删除有缓冲期 | 误删错题无法恢复 |
| 6 | **渐进披露** | 核心功能一步可达，高级功能按需展开 | 注册时就要求填写所有个人信息 |

### 1.2 双用户群体设计策略

我们的用户跨越**8岁到15岁**的认知差异区间，这是最大的设计挑战。

| 维度 | 小学生（3-6年级 / grade 31-36） | 初中生（7-9年级 / grade 71-73） |
|------|-------------------------------|-------------------------------|
| **认知特征** | 具象思维为主，注意力集中时间短（10-15min） | 抽象思维发展中，能处理数据化信息 |
| **使用动机** | 外部驱动（家长要求）→ 需转化为内部驱动（有趣/有成就） | 内部驱动为主（考试压力/提分需求） |
| **操作能力** | 手指较小，精细操作弱，易误触 | 接近成人操作水平 |
| **阅读偏好** | 大字号、图标辅助、口语化短句 | 标准字号、文字为主、专业术语可接受 |
| **情感需求** | 即时正反馈、被表扬、视觉奖励 | 效率感、掌控感、数据化成长可见 |
| **MVP策略** | 通用UI偏年轻活泼 + 专属适配项（见下文） | 通用UI保持简洁克制 + 专属适配项 |

**MVP阶段核心策略：一套UI兼顾两个群体，通过以下机制实现差异化：**

| 差异化机制 | 说明 | MVP实现 |
|-----------|------|---------|
| 文案自适应 | 根据grade显示不同措辞 | ✅ 错因标签文案（PRD FR-300-5） |
| 选项自适应 | 小学生多一个"不确定"错因 | ✅ FR-300-8 |
| 图标辅助 | 小学生版错因带表情图标 | ✅ FR-300-5a |
| 字号弹性 | 基础字号统一，关键区域小学生略大 | ✅ 正文16px/标题18px vs 正文14px/标题16px |
| 色彩情绪 | 统一色板，但小学生模式饱和度略高 | ⚠️ MVP微调，V1.1完整分模式 |
| 手动切换 | 用户可在设置中切换模式 | ❌ V1.1实现 |

#### 1.3.3 间距系统

采用 **4px 基准网格**，所有间距为4的倍数：

| Token | 值 | 用途 |
|-------|-----|------|
| xs | 4px | 图标与文字间距、紧凑元素间 |
| sm | 8px | 同组元素间距、标签内边距 |
| md | 12px | 卡片内元素间距 |
| base | 16px | 页面水平安全边距、卡片间距 |
| lg | 20px | 模块间距 |
| xl | 24px | 区块间距 |
| xxl | 32px | 页面顶部/底部留白 |
| xxxl | 48px | 大区块分隔 |

**页面安全边距：** 左右各 16px（所有屏幕尺寸统一）

#### 1.3.4 圆角系统

| Token | 值 | 用途 |
|-------|-----|------|
| radius-sm | 4px | 标签、小按钮 |
| radius-md | 8px | 输入框、下拉菜单 |
| radius-lg | 12px | 卡片、面板 |
| radius-xl | 16px | 大卡片、弹窗 |
| radius-full | 999px | 圆形按钮、头像、进度条 |

> **设计调性说明：** 圆角整体偏大（12-16px），营造亲和、安全的视觉感受，避免尖锐棱角带来的紧张感。这对小学生用户尤为重要。

## 2. 信息架构

### 2.1 全局导航结构

APP采用**底部Tab栏 + 居中浮动录入按钮**的经典布局：

```
┌─────────────────────────────────────────┐
│                                         │
│              （页面内容区）               │
│                                         │
├──────────┬──────────┬────────┬──────────┤
│          │          │   ＋   │          │
│  🏠 首页  │ 📚 错题本 │  录入  │ 👤 我的   │
│          │          │(浮动)  │          │
└──────────┴──────────┴────────┴──────────┘
```

| Tab | 图标 | 标签 | 核心功能 | 角标规则 |
|-----|------|------|---------|---------|
| 首页 | house | 首页 | Dashboard概览、今日任务入口 | 无 |
| 错题本 | books | 错题本 | 错题列表、筛选、搜索、详情 | 无 |
| 录入 | plus-circle-fill | （无标签） | 拍照/相册→裁剪→确认→保存 | 无 |
| 我的 | user | 我的 | 个人设置、周报、存储管理 | 同步失败时显示红点 |

**录入按钮特殊设计：**
- 形态：56×56px 圆形浮动按钮，居中悬浮于Tab栏上方
- 颜色：Brand Primary `#4F6EF7`，白色"+"图标
- 阴影：`0 4px 12px rgba(79,110,247,0.3)`
- 点击效果：缩放至0.9 + 涟漪扩散
- 长按：快捷弹出"拍照"/"相册"两个选项（可选优化）

### 2.3 核心用户旅程

#### 旅程A：新用户首次体验（下载 → 注册 → 录入第一道错题）

**目标：** 3分钟内完成注册并成功录入第一道错题，感受到"简单好用"。

```
[打开APP] 
    ↓ 0s
[P1 启动页] — 品牌Logo + Slogan "消灭错题，成为学霸猎手"
    ↓ 1.5s 自动跳转 / 点击跳过
[P1 引导页] — 3页滑动引导（≤5秒可跳过）
    ↓ 
[P2 注册页] — 手机号 → 验证码 → 选年级 → 勾选家长同意
    ↓ ~60s
[注册成功] → 自动登录 → Toast "欢迎加入错题猎手！"
    ↓ 
[P3 首页] — 空状态引导："拍一道错题试试？" + 箭头指向录入按钮
    ↓ 
[点击＋录入] 
    ↓ 
[P4 Step1] — 拍照/选图 → 自动裁剪 → 确认裁剪区域
    ↓ ~10s
[P4 Step2] — OCR结果展示 → AI推荐错因/知识点（高亮标记）
    ↓ ~15s  
[P4 Step3] — 选错因粗分类（必填）→ 点击"保存并加入复习计划"
    ↓ 
[Toast "录入成功，已加入复习计划"] → 返回首页
    ↓
[P3 首页] — 统计更新：累计错题 1 | 今日待复习 0（明天开始）
```

**关键体验节点：**
- 引导页提供"跳过"按钮，尊重老用户
- 年级选择在验证码之后（降低注册门槛）
- 录入成功后明确告知"已加入复习计划"，建立预期
- 首页空状态不是空白，而是行动引导

#### 旅程B：日常使用（打开APP → 查看待复习 → 完成复习）

**目标：** 打开APP即知道今天要做什么，5-15分钟完成一轮复习。

```
[收到推送 19:00] "你今天有5道错题等你复习哦！坚持就是胜利 💪"
    ↓ 
[打开APP] → 自动进入 P3 首页
    ↓ 
[看到今日任务卡片] "待复习 5 道" + [开始复习] 按钮
    ↓ 点击
[P7 复习页] — 进度条 "1/5"
    ↓
[卡片正面] — 题目图片/文字，答案区域模糊遮挡
    ↓ 在纸上重做
[点击"显示答案"] — 卡片翻转（0.3s动画）
    ↓
[卡片背面] — 正确答案 + 解题过程 + 我的错误答案 + 错因 + 知识点
    ↓ 对比自评
[三按钮] [完全掌握🟢] [部分记得🟡] [完全不会🔴]
    ↓ 选择
[左滑动画] → 下一题 "2/5"
    ↓ ×5
[复习报告] — 今日复习5道 | 掌握3 | 部分1 | 不会1 | 用时8分钟
    ↓ [返回首页]
[P3 首页] — 打卡天数+1，统计数据刷新
```

**关键体验节点：**
- 首页"今日任务"是最醒目的CTA，不需要找入口
- 复习过程沉浸式全屏，不被其他信息干扰
- 翻转后信息层次清晰：先看答案对不对 → 再看为什么错
- 复习报告给予即时总结反馈

#### 旅程C：成就感时刻（消灭错题的完整体验流）

**目标：** 让"消灭"成为一个记忆深刻的正向高峰体验。

```
[复习第5轮] — 某道错题的第5次复习
    ↓
[自评"完全掌握"] — master_count 达到 3
    ↓
[触发消灭] 
    ↓
[P8 消灭动画] — 全屏覆盖（≤2秒）
    ├─ 0.0-0.8s: 当前卡片碎裂消散
    ├─ 0.5-1.7s: 彩色粒子撒花
    ├─ 0.8-2.0s: 文字浮现 "又消灭一道错题！🎉"
    └─ 1.2-2.0s: 累计消灭数 "已消灭 47 道" 
    ↓ 自动关闭 / 点击跳过
[返回复习流] — 继续下一题 或 显示复习报告
    ↓
[首页更新] — 已消灭数+1，消灭率更新，日历标记
```

**关键体验节点：**
- 动画仅在首次消灭时播放（FR-601-5），避免审美疲劳
- 动画不阻塞操作，可随时跳过
- 累计消灭数是持续可见的成就指标
- 里程碑（10/50/100道）额外庆祝提示

#### 自评撤销交互（V1.1 新增）

> **背景：** 防止用户误触自评按钮导致数据不可逆。小学生手指操作精度低，误触概率高。

**交互流程：**

```
用户点击 [完全掌握 🟢]
  ↓
按钮变为选中态（绿色高亮）
底部 Snackbar 浮现（4秒倒计时）：
┌─────────────────────────────────────┐
│ 已标记为"完全掌握"         [ 撤销 ]  │
└─────────────────────────────────────┘
  ↓ 4秒内未操作
Snackbar 消失 → 提交到服务端 → 卡片左滑出场 → 下一题

  ↓ 4秒内点击"撤销"
按钮恢复默认态 → Toast "已撤销" → 等待用户重新选择

  ↓ 4秒内用户左滑切到下一题
立即提交上一题评价 → Snackbar 消失 → 加载下一题
```

**交互规格：**

| 项目 | 规格 |
|------|------|

| Snackbar 样式 | Snackbar 标准样式（深色底+白色文字+"撤销"Ghost 按钮） |
| 提交时机 | 4 秒窗口结束后才真正提交到服务端 |
| 左滑行为 | 立即提交上一题 + 隐藏 Snackbar + 加载下一题 |
| 退出复习页 | 如有未提交的 pending 评价，立即提交后退出 |

| 卡片碎裂 | 0-0.8s | scale: 1→0, opacity: 1→0, easing: ease-in-out | 当前复习卡片从中心向四周碎裂缩小消失 |

| 文字浮现 | 0.8-1.5s | translateY: 20→0, opacity: 0→1, font: H1 Bold | "又消灭一道错题！🎉" 从下方浮入 |
| 计数展示 | 1.2-2.0s | 数字countUp动画, font: Number Bold 28px | "已消灭 47 道" 数字递增到目标值 |

**交互规则：**

| 规则 | 说明 |
|------|------|
| 触发条件 | master_count达到3，状态变为MASTERED时(FR-601-1) |
| 仅首次 | 复活后再次消灭不播放(FR-601-5) |
| 可跳过 | 点击屏幕任意位置立即结束动画(FR-601-4) |
| 可关闭 | 设置中"消灭动画"开关关闭后不播放(FR-601-6) |
| 不阻塞 | 动画播放期间后台已完成状态变更和数据更新 |
| **实现方式** | **使用 Lottie 预渲染动画**（非 Flutter 实时粒子计算）。动画参数仅供动画设计师制作 Lottie 文件时参考，客户端使用 `lottie` 包播放预渲染 JSON |
| **同轮连续消灭** | 同一轮复习中多道题同时达到消灭条件时，**仅首次播放完整动画（≤2秒）**，后续消灭使用简化 Toast（≤0.5秒） |

#### 同轮连续消灭简化规格（V1.1 新增）

> **背景：** 一轮复习 8 道题中可能有 3-5 道同时达到消灭条件。如果每道都播 2 秒完整动画，用户需等待 6-10 秒，严重影响复习节奏。

| 场景 | 动画表现 | 时长 |
|------|---------|------|
| 同轮**首次**消灭 | 完整 Lottie 动画：碎裂+撒花+文字+计数 | ≤ 2.0秒 |
| 同轮**第 2+ 次**消灭 | 简化 Toast 浮层 | ≤ 0.5秒 |

**简化 Toast 设计：**

```
┌──────────────────────────────────┐
│                                  │
│     🎉 又消灭一道！              │ ← H3 Bold
│     已消灭 48 道 🎯              │ ← Number Bold 28px
│                                  │
└──────────────────────────────────┘
背景：半透明黑色(60%)  圆角：radius-xl
位置：屏幕中央  动画：fadeIn(100ms) → 停留300ms → fadeOut(100ms)
```

## 7. 竞品设计对标与超越策略

### 7.1 竞品设计优缺点提取

| 竞品 | 设计优点 | 设计缺点 |
|------|---------|---------|
| **橙果错题本** | 录入流程简洁高效；去手写效果视觉明显；导出排版规整 | 学情报告视觉粗糙；无游戏化元素；界面略显老旧(8年产品) |
| **错题Plus** | 功能丰富度高；微课视频嵌入体验好 | 界面臃肿、信息过载；付费墙频繁打断体验；视觉风格不统一 |
| **巧学错题本** | 极简克制、上手快；录入速度快 | 缺少数据可视化；无激励体系；设计缺乏品牌辨识度 |

### 7.2 我们的设计超越策略

| 维度 | 竞品现状 | 我们的超越点 | 具体交互细节 |
|------|---------|------------|-------------|
| **录入体验** | 橙果最优：拍照→自动裁剪→保存 | 对标橙果+增加AI推荐确认环节 | 3步流程中Step2展示AI推荐(✨标记)，用户一键确认而非从零填写；比橙果多了归因环节但不增加操作负担 |
| **错因归因** | 全部竞品仅基础标签/简单统计 | 二级归因+可视化饼图+趋势分析 | 错因选择做成直觉化卡片(小学生带Emoji)；饼图可交互点击查看明细；首页直接展示错因分布，无需跳转分析报告 |
| **复习体验** | 全部竞品无间隔复习机制 | 卡片翻转+三按钮自评+沉浸式全屏 | 参考Anki但大幅简化：Anki有4级评分我们只有3级；Anki纯文字我们有图片+结构化信息；Anki无消灭动画我们有正向反馈 |
| **消灭闭环** | 竞品只有"有/无"两态 | 三态生命周期+进度可视化+消灭动画 | 进度条渐变色直观展示复习进度(红→绿)；消灭动画≤2秒不阻塞但有仪式感；隐藏master_count防止刷自评 |
| **激励体系** | 全部竞品无游戏化 | 打卡+消灭计数+里程碑+日历 | 打卡天数放在首页最显眼位置；消灭数字有CountUp动画；日历热力图让坚持"看得见" |
| **信息层次** | 错题Plus臃肿、巧学过于简单 | 精准分层：核心任务L0-L1，数据洞察L3-L5 | 首页用优先级排列7个模块，最重要的"今日任务"最大最醒目；数据图表可折叠/展开 |
| **双群体适配** | 竞品均为单一UI风格 | 基于年级的配置化UI适配 | 同一套代码通过10+配置变量实现差异化；小学生大按钮+Emoji+口语化；初中生标准+数据驱动 |
| **离线体验** | 竞品均不支持离线 | 离线可用+同步状态透明 | 首页常驻同步状态图标；离线录入有明确Toast提示；联网后自动静默同步 |

### 7.3 设计差异化总结

> **一句话：** 竞品做的是"错题记录工具"，我们做的是"错题消灭系统"。设计上要让用户**第一眼就感受到"这不是又一个错题本"**。

| 差异化感知点 | 用户首次体验时的感受 |
|-------------|-------------------|
| 首页"今日待复习"卡片 | "它告诉我今天该做什么，不用我自己想" |
| 错因选择带Emoji | "选错因不像在做问卷，像在表达感受" |
| 复习卡片翻转 | "像翻牌一样，有点期待看到答案" |
| 消灭动画 | "消灭一道题居然这么爽？！" |
| 打卡天数+日历 | "已经坚持12天了，不能断" |
| 进度条渐变色 | "这道题快到绿色了，再复习几次就能消灭" |

### 8.1 色彩对比度标准

| UI组件/图形 | 3:1 | WCAG 2.1 AA级 |
| 装饰性元素 | 无要求 | — |

**色彩验证清单：**
- ✅ Text Primary `#1A1A2E` on Background `#F8F9FC` → 对比度 15.2:1
- ✅ Text Secondary `#6B7280` on Surface `#FFFFFF` → 对比度 5.0:1
- ✅ Brand Primary `#4F6EF7` on Surface `#FFFFFF` → 对比度 3.5:1 (仅用于大号文字/UI组件)
- ✅ White `#FFFFFF` on Brand Primary `#4F6EF7` → 对比度 3.5:1 (按钮文字，大号)
- ✅ Danger `#D32F2F` on Surface `#FFFFFF` → 对比度 4.63:1 (WCAG AA 达标，可用于正文和按钮)
- ✅ White `#FFFFFF` on Danger `#D32F2F` → 对比度 4.63:1 (按钮文字，达标)
- ⚠️ 旧色值 `#FF5252` 对比度仅 3.3:1，已在 V1.1 修订中全面替换为 `#D32F2F`

### 8.2 字号最小值

| 场景 | 最小字号 | 说明 |
|------|---------|------|
| 可读正文 | 14px (初中生) / 16px (小学生) | 低于此值阅读困难 |
| 辅助标注 | 12px (初中生) / 14px (小学生) | 仅限非关键信息(时间戳等) |
| 绝对最小值 | 12px | 任何情况下不低于此值 |
| 动态字体 | 支持系统字体缩放 | Flutter MediaQuery.textScaleFactor |

### 8.3 触控目标最小尺寸

| 场景 | 最小尺寸 | 依据 |
|------|---------|------|
| 可点击元素 | 44×44pt (iOS) / 48×48dp (Android) | Apple HIG / Material Design |
| 密集列表项 | 最小行高48dp | Material Design |
| 按钮 | 高度≥48px，宽度≥80px | 通用标准 |
| 小学生增强 | 高度≥52px | 考虑手指较小+精细操作弱 |
| 间距 | 相邻可点击元素间距≥8px | 防误触 |

### 8.5 其他包容性考量

| 维度 | 措施 |
|------|------|
| 动画敏感 | 尊重系统"减少动画"设置；开启后消灭动画简化为淡入淡出 |
| 屏幕阅读器 | 所有图片有语义化alt文本；按钮有明确label；进度条有aria-valuenow |
| 色盲友好 | 状态不仅靠颜色区分，同时使用图标(🔴🟡✅⭐)和文字标签 |
| 左手操作 | 录入浮动按钮居中，不偏向某一侧；关键操作双侧可达 |
| 网络慢 | 所有图片支持渐进加载；核心功能离线可用；弱网下有明确状态提示 |
