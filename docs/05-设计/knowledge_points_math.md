# 数学知识点体系（课程标准参考）

> 用途：错题猎手「添加错题 → 知识点选择」的静态参考知识点清单。
> 来源依据：《义务教育数学课程标准（2022 年版）》+ 人教版教材编排。
> 性质：课程标准参考数据（非用户私有数据），前端内置，无需后端接口。
> 学科：数学（本期仅支持数学；语文/英语暂不排期）。
> 状态：**已迁移至后端**。前端静态文件已删除，知识点由后端配置文件驱动，app 通过 API 拉取。

---

## 设计约定

- **年级代码**（与 `register_page.dart` 一致）：
  - `31` 三年级 / `32` 四年级 / `33` 五年级 / `34` 六年级
  - `71` 七年级 / `72` 八年级 / `73` 九年级
- **知识领域**（parentId，对应课标领域；综合与实践暂不列入错题归因）：
  - `num` 数与代数
  - `geo` 图形与几何
  - `stat` 统计与概率
- **知识点 ID 规则**：`m<年级代码>_<领域>_<两位序号>`，学科前缀 `m` 预留，便于以后加语文/英语不冲突。如 `m31_num_01` = 三年级·数与代数·万以内加减法。
- **isRecommended**：标记该年级最基础、出错频率最高的知识点（每年级 4–6 个），用于「推荐知识点」区（带 ✨）。
- **命名口径**：允许口语化，便于学生辨认；与人教版小节对应但不逐字照搬。

## 落地说明（已迁移至后端）

知识点不再前端内置，改为后端配置驱动：

- **后端配置（唯一编辑源头）**：`src/errorhunter_server/configs/knowledge_points.yaml`（即本文档的 87 条）。修改后重启后端即生效。
- **后端种子**：`internal/service/knowledge_point_seeder.go` 启动时幂等 upsert 到 `knowledge_points` 表（grade/domain/is_recommended/subject 编码进 `keywords` JSONB，不改表结构）。
- **后端 API**：`GET /v1/knowledge-points?grade=<code>&subject=数学`，返回 `{items:[{id,name,subject,parent_id,is_recommended}]}`。
- **App 拉取**：`KnowledgePointRemoteDataSource` → `KnowledgePointRepository`（DI 注册），`add_question_page` 第 2 步按当前用户年级异步拉取，加载中转圈、失败可重试。
- 用户仍可通过选择器底部输入框添加自定义知识点；保存时后端按 name find-or-create 并关联。
- 年级为空（异常情况）时清单为空，用户仍可手动添加自定义知识点。

> 重命名一个知识点会在 DB 新增行并遗留旧行（旧错题仍关联旧行）；如需真正重命名请手工处理数据库。
