## 🔴 必须立即修复的问题（三维度交叉验证）

以下是被 **多个测试维度同时发现** 的高优先级问题，修复优先级最高：

### 1. 🚨 复习页沉浸模式切后台 → 系统 UI 永久隐藏

| 维度 | 发现 |
|------|------|
| 🚶 走查 | 全屏沉浸模式进入/退出管理 |
| 📱 真机 | App 被系统杀后恢复，沉浸模式可能泄漏到其他页面 |

- **位置**: `review_page.dart:44,52`
- **修复**: 改用 `WidgetsBindingObserver` 监听生命周期，仅在页面真正可见时设置沉浸模式；将恢复模式改为与应用全局一致的模式而非硬编码 `edgeToEdge`

### 2. 🚨 相机/相册权限完全未处理

| 维度 | 发现 |
|------|------|
| 📱 真机 | 直接调用 ImagePicker，无权限预检 |
| 🎯 UX | 原则 5 错误预防 — 用户拒绝权限后无引导 |

- **位置**: `add_question_page.dart:97-143`
- **修复**: 在 `_pickImage` 前添加权限检查 → 请求 → 拒绝后引导弹窗的完整流程
- **影响**: 拍照录入错题是核心功能，真机上大概率静默失败

### 3. 🚨 Splash 页竞态条件 → 已登录用户被导向引导页

| 维度 | 发现 |
|------|------|
| 🚶 走查 | 1.5s Timer 与网络 Token 验证竞态 |
| 🎯 UX | 固定延迟无加载指示，违反系统状态可见性 |

- **位置**: `splash_screen.dart:52-71`
- **修复**: 改为监听 AuthBloc 状态变化后再跳转，设最大超时 5 秒并显示 loading indicator

### 4. 🚨 编辑/保存操作无防抖、无错误处理

| 维度 | 发现 |
|------|------|
| 🚶 走查 | 连续点击导致多次提交 |
| 🎯 UX | 原则 5 错误预防 — 缺少防重复提交机制 |

- **位置**: `question_detail_page.dart:64-83`
- **修复**: 添加 `isSaving` 锁 + BLoC 层 try-catch 错误状态 emit

### 5. 🚨 首页硬编码样式绕过主题系统 → 双群体适配失效

| 维度 | 发现 |
|------|------|
| 🎯 UX | 数十处硬编码 TextStyle，`AppTypography.forGrade()` 机制被架空 |
| 📱 真机 | 系统字体最大时大字号文本溢出 |

- **位置**: `home_page.dart:94-96, 112, 309, 328, 392` 等
- **修复**: 将所有硬编码 TextStyle 替换为 `context.textStyle` 或 `AppTheme.forGrade(grade)` 获取
- **影响**: 初中生看到小学生 UI，核心差异化体验缺失

### 6. 🚨 用户协议/隐私政策链接未实现（合规风险）

| 维度 | 发现 |
|------|------|
| 🚶 走查 | onTap 为空 TODO |
| 🎯 UX | 面向未成年人产品，合规性严重缺失 |

- **位置**: `register_page.dart:323, 335`
- **修复**: 实现 WebView 或内置富文本页面展示协议内容

## 附录：测试方法说明

### 🚶 `/walkthrough` — 模拟走查

模拟真实用户从 App 启动开始，逐步操作每个页面，检查：
- **视觉**：标题、空状态、加载状态、错误状态、长文本溢出
- **交互**：点击反馈、防重复、表单校验、键盘遮挡、返回逻辑
- **状态**：数据增删改后列表刷新、网络断开提示、分页终止
- **异常**：快速连续点击、加载中返回、切后台再回来

### 📱 `/real-device` — 真机 Checklist

基于行业最佳实践的 8 大真机专属检查类别：
1. 屏幕与布局（设备碎片化、SafeArea、动态字体）
2. 手势与触摸交互（热区 ≥ 48dp、嵌套滚动、手势冲突）
3. 键盘与输入（遮挡、focus 切换、输入法兼容）
4. App 生命周期（后台恢复、Activity 重建、Timer 管理）
5. 网络环境（弱网超时、断网提示、恢复重试）
6. 权限与系统交互（相机/相册/通知/存储权限）
7. OEM 与系统差异（导航栏差异、深色模式、iOS 橡皮筋）
8. 性能（首屏加载、懒加载、图片缓存、内存泄漏）

### 🎯 `/heuristic` — UX 启发式评估

基于 Nielsen 10 大启发式原则 + 4 条移动端 UX 专项：
1. 系统状态可见性
2. 系统与现实匹配
3. 用户控制与自由
4. 一致性与标准
5. 错误预防
6. 识别而非回忆
7. 灵活性与效率
8. 美学与极简
9. 错误恢复
10. 帮助与文档
11. 拇指可达性
12. 操作反馈即时性
13. 渐进式披露
14. 双群体适配（小学生 vs 初中生）
