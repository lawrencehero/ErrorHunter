## 四、PRD变更清单（共8项）

基于本次讨论，对PRD V1.0进行以下变更：

### 变更1：新增FR-203 简版PDF导出

**位置：** 功能5.2 错题采集（新增子功能）

| 编号 | 规则 |
|------|------|
| FR-203-1 | 导出格式：PDF（客户端本地生成） |
| FR-203-2 | 每道错题占一页，内容：题目图片 + 错因标签 + 知识点标签 |
| FR-203-3 | 按录入时间倒序排列 |
| FR-203-4 | 单次最多导出50道错题 |
| FR-203-5 | 支持按时间范围筛选：本月 / 近3个月 / 全部 |
| FR-203-6 | 0道错题时导出按钮置灰，提示"暂无错题可导出" |
| FR-203-7 | 生成后调用系统分享（iOS Share Sheet / Android Intent） |
| FR-203-8 | 离线状态下，仅可导出已同步到本地的错题图片 |
| FR-203-9 | 图片未上传成功的错题，导出时图片位置显示占位图+提示"图片待同步" |

### 变更2：FR-300 错因标签增加"不确定"选项

**位置：** 功能5.3 归因分析 → FR-300

| 编号 | 规则 |
|------|------|
| FR-300-8 | 小学生用户（grade 31-36）的错因粗分类增加第5个选项："不确定"（图标🤷） |
| FR-300-9 | 选择"不确定"的错题**不纳入**错因分布饼图统计 |
| FR-300-10 | 选择"不确定"的错题**纳入**错题总数和消灭率统计 |
| FR-300-11 | 初中用户（grade 71-73）不展示"不确定"选项 |
| FR-300-12 | "不确定"选项在学情周报中标记为"待确认错因" |

**枚举值新增：**

| 枚举值 | 含义 | 小学生显示文案 | 适用学段 |
|--------|------|--------------|---------|
| UNKNOWN | 不确定 | 🤷 不确定 | 仅小学 |

### 变更3：OCR规格增加去手写评估要求

**位置：** 功能5.2 → FR-200 OCR服务规格

| 项目 | 规格（新增） |
|------|-------------|
| 去手写能力 | 第三方OCR需具备教育场景去手写能力，能分离印刷题目与手写笔迹 |
| 去手写评估 | 选型时需测试：①纯印刷体（无手写）准确率 ②带手写答案的试卷去手写后印刷体准确率 ③手写答案残留率 |
| 去手写降级 | 若去手写效果不佳，保留原始图片，OCR结果标注"含手写内容，请核对原图" |

### 变更4：FR-700 激励体系增加消灭进度可视化

**位置：** 功能5.7 激励体系

| 编号 | 规则 |
|------|------|
| FR-700-5 | 错题详情页展示"复习进度条"：当前轮次 / 共5轮（如"第3轮 / 共5轮"） |
| FR-700-6 | 进度条使用渐变色：红(1轮) → 橙(2轮) → 黄(3轮) → 浅绿(4轮) → 绿(5轮) |
| FR-700-7 | **不展示master_count**（隐藏"连续掌握N次"的具体数字），防止用户刷自评 |
| FR-700-8 | 首页错题卡片上展示微型进度条（高度4px），直观展示各题复习进度 |
| FR-700-9 | 已消灭的错题进度条显示为绿色满格 + ✅图标 |

### 变更5：GR-002 离线规则简化为单向上传

**位置：** 全局规则 4.2

| 编号 | 规则（修改） |
|------|-------------|
| GR-002-1 | 支持离线录入错题（数据存储在本地SQLite） |
| GR-002-2 | 支持离线复习（缓存当日待复习数据） |
| GR-002-3 | 联网后自动**单向上传**本地数据到服务端（不做双向同步） |
| GR-002-4 | 上传队列：图片先传OSS获取URL → 再传错题数据 → 标记为已同步 |
| GR-002-5 | 上传失败策略：最多重试3次，指数退避（1s→2s→4s），3次失败标记FAILED |
| GR-002-6 | 首页展示同步状态图标：✅已同步 / ⏳待同步 / ❌同步失败（点击可手动重试） |
| GR-002-7 | MVP不支持多设备间数据同步（用户在哪台设备录入就在哪台使用） |
| GR-002-8 | V1.1规划：双向同步 + 多设备同步 + 冲突版本保留 |

### 变更6：FR-500 复活检测增加优先级和降频策略

**位置：** 功能5.5 消灭机制 → FR-500-4

| 编号 | 规则（修改/新增） |
|------|-----------------|
| FR-500-4a | 复活检测每日上限：3道（不变） |
| FR-500-4b | 优先级：按消灭时间（mastered_at）最早的优先检测 |
| FR-500-4c | 降频策略：已通过复活检测且再次满30天的错题，下次检测间隔提升为60天 |
| FR-500-4d | 再次通过60天检测后，下次间隔提升为90天 |
| FR-500-4e | 通过90天检测后标记为"永久消灭"（PERMANENTLY_MASTERED），不再复活检测 |
| FR-500-4f | 复活失败时的文案：不使用"复活"字样，使用鼓励式表达，如"这道题需要再巩固一下哦！" |
| FR-500-4g | 复活检测的UI入口：出现在每日复习列表的最后，与正常复习题视觉区分（加"复习检测"标签） |

**新增状态：**

| 枚举值 | 含义 | 颜色标识 |
|--------|------|---------|
| PERMANENTLY_MASTERED | 永久消灭（通过90天检测） | 深绿色 |

### 变更7：questions表增加AI预留字段

**位置：** 数据字典 7.2 → questions表

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| ai_error_analysis | TEXT | 否 | AI生成的错因深度分析文本（V1.1） |
| ai_knowledge_gaps | JSON | 否 | AI识别的前置知识缺失链（V1.1） |
| ai_suggested_exercises | JSON | 否 | AI推荐的同类题列表（V1.1） |
| ai_analyzed_at | DATETIME | 否 | AI分析执行时间（V1.1） |

> 注：以上字段MVP阶段均为NULL，V1.1上线时填充。

### 变更8：新增数据埋点规范

**位置：** 全局规则（新增 4.4 数据埋点规则）

**GR-004 数据埋点规则**

| 编号 | 规则 |
|------|------|
| GR-004-1 | MVP上线第一天即启用埋点，不做后置补点 |
| GR-004-2 | 核心路径埋点：注册完成 → 首次录入 → 首次复习 → 首次消灭 |
| GR-004-3 | 留存埋点：每日打开APP、每日完成复习 |
| GR-004-4 | 功能使用埋点：PDF导出次数、错因修改次数、OCR失败次数 |
| GR-004-5 | 北极星指标自动计算：7日留存率、30日留存率、WAU/MAU、日均复习完成率、错题消灭率 |
| GR-004-6 | 埋点方案：MVP使用Firebase Analytics（免费额度足够），V1.1评估是否需要自建 |
