## 一、技术选型（MVP 阶段）

| 模块 | 技术方案 | 说明 |
|------|---------|------|
| 客户端 | Flutter | 跨端（iOS + Android），一套代码 |
| 后端 | Go / Java 单体服务 | MVP 不拆微服务 |
| 数据库 | PostgreSQL | 主数据库，强一致性 |
| 缓存 | Redis | 缓存 + 消息队列 |
| 图片存储 | 阿里云 OSS | 对象存储，按用户隔离 |
| OCR | 第三方 API（百度/腾讯） | 待选型对比 |
| 推送 | 极光 / 个推 | 待选型对比 |

## 三、核心模块技术设计

### 3.1 复习调度引擎

- 基于艾宾浩斯遗忘曲线
- 定时任务每天凌晨 00:00 计算当日待复习列表
- 每日上限 20 道，超出顺延
- 积压 >50 道触发"大扫除"模式

### 3.2 OCR 服务

- 接入第三方 API
- 单次调用超时 5 秒
- 失败降级为手动输入
- 原始图片永久保存

### 3.3 图片存储

- 阿里云 OSS
- 按用户 ID 分桶存储
- 签名 URL，有效期 30 分钟
- 用户存储上限 5GB
