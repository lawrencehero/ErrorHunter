## 1. 技术选型详细论证

### 1.1 Go vs Java 后端选型对比

| 维度 | Go (1.22+) | Java (21 + Spring Boot 3) | 权重 | 评判 |
|------|-----------|--------------------------|------|------|
| **并发性能** | goroutine 轻量级协程，单机轻松承载 10w+ 并发连接；内存占用 ~2KB/goroutine | 虚拟线程(Loom)改善显著，但 JVM 基础内存开销仍 ~200MB+ | ⭐⭐⭐ | Go ✅ |
| **启动速度** | 编译为二进制，冷启动 < 100ms | JVM 预热 3-10s（GraalVM Native 可降至 < 1s，但生态兼容有坑） | ⭐⭐ | Go ✅ |
| **开发效率** | 语法简洁，标准库强大；ORM(GORM)够用但不及 MyBatis-Plus 丰富 | Spring 全家桶开箱即用，CRUD 脚手架成熟 | ⭐⭐⭐ | Java ✅ |
| **生态/中间件** | gin/echo/fiber + GORM + go-redis + zap，MVP 足够 | Spring Cloud Alibaba 一站式微服务方案 | ⭐⭐ | MVP 阶段平手 |
| **团队能力** | 当前团队 2 人有 Go 项目经验，1 人纯 Java | 3 人均有 Java 经验 | ⭐⭐ | Go 需学习成本 |
| **运维复杂度** | 单二进制部署，Docker 镜像 ~15MB | JRE 镜像 ~300MB+，GC 调优门槛 | ⭐⭐ | Go ✅ |
| **长期扩展** | 天然适合微服务拆分；gRPC 一等公民 | Spring Cloud 体系完善但重 | ⭐ | MVP 不拆微服务，平手 |
| **社区/招聘** | Go 在国内云原生/教育科技赛道人才增长快 | Java 人才池最大 | ⭐ | 平手 |

#### 🏁 明确结论：**选择 Go**

**核心理由：**

1. **MVP 是单体服务**——Go 的编译型 + 低内存特性意味着一台 2C4G 服务器即可支撑万级 DAU，节省早期云资源成本约 40%
2. **复习调度引擎是 CPU 密集 + 定时任务场景**——goroutine + channel 天然适配，无需引入额外消息队列框架
3. **竞品窗口期紧迫**（参见竞品报告 §7.2）——更快的部署迭代 = 更多试错机会
4. **团队学习成本可控**——Go 语法简单，2 周上手，1 个月达到生产水平；PRD 中 MVP 预计 14 周，时间充裕
5. **V1.1 AI 模块预留**——AI 推理服务通常用 Python，Go 通过 gRPC/HTTP 调用无碍，Java 并无优势

**MVP 妥协点：** ORM 选用 GORM，复杂查询手写 SQL；暂不引入微服务框架，单体模块化（见 §2.3）。

### 1.3 PostgreSQL vs MySQL 对比

| 维度 | PostgreSQL 16 | MySQL 8.0 | 评判 |
|------|--------------|-----------|------|
| **JSON 支持** | JSONB 二进制存储，GIN 索引，jsonpath 查询 | JSON 文本存储，仅虚拟列索引 | PG ✅ |
| **数组类型** | 原生 TEXT[]/INT[]，ANY/ALL/unnest | 不支持原生数组 | PG ✅ |
| **部分索引** | WHERE deleted_at IS NULL 条件索引 | 不支持 | PG ✅ |
| **全文搜索** | tsvector/tsquery + pg_jieba 中文分词 | FULLTEXT 中文支持弱 | PG ✅ |
| **扩展性** | pg_trgm/pg_cron/timescaledb/pgvector | 插件生态较弱 | PG ✅ |
| **ACID 严格性** | MVCC + 真正 SERIALIZABLE | next-key lock 伪串行化 | PG ✅ |
| **运维熟悉度** | 团队经验较少 | 团队更熟悉 | MySQL ✅ |
| **云服务支持** | 阿里云 RDS PG 全功能托管 | 阿里云 RDS MySQL 全功能托管 | 平手 |

#### 🏁 明确结论：**选择 PostgreSQL 16**

**核心理由：** PRD 数据模型大量使用 JSON（solution_steps/custom_tags/keywords），PG 的 JSONB + GIN 索引是刚需；部分索引直接命中需求；V1.1 可能需要 pgvector 向量检索。

### 2.2 各层职责定义

| 层级 | 职责 | 约束 |
|------|------|------|
| **客户端层** | UI渲染、本地状态管理、离线存储、图片预处理、埋点采集 | 不含业务逻辑决策 |
| **API Gateway层** | TLS终止、L7限流、JWT格式预校验、CORS、压缩 | 不做业务鉴权 |
| **服务层** | 全部业务逻辑、数据校验、权限判定、第三方编排、定时任务 | 单体模块化，interface调用 |
| **数据层** | 持久化、缓存、对象存储、外部API代理 | DB不暴露给客户端 |

### 2.5 同步/异步通信边界

| 通信方式 | 场景 | MVP |
|---------|------|-----|
| 同步HTTP | 所有客户端→服务端API | MVP |
| 进程内goroutine | Dashboard离线计算、周报生成 | MVP |
| Redis Sorted Set延迟队列 | 软删除清理、复习提醒 | MVP |
| Ticker goroutine | 每日00:00复习调度刷新 | MVP |
| gRPC | Go↔Python AI服务 | V1.1 |
| 消息队列 | 跨服务异步事件 | V2.0 |

> **MVP原则：** 能用goroutine+Redis解决的，不上消息队列。

### 2.6 第三方服务集成架构

```

├── Firebase Analytics SDK (客户端集成)

```

**适配器模式要点：** interface+具体实现；配置驱动切换；统一错误码映射；超时+重试(MVP)，V1.1加熔断。

```sql
-- ============================================================
-- 枚举类型（PostgreSQL TYPE）
-- ============================================================

-- 年级枚举
CREATE TYPE grade_enum AS ENUM (
    '31',  -- 小学三年级
    '32',  -- 小学四年级
    '33',  -- 小学五年级
    '34',  -- 小学六年级
    '71',  -- 初中一年级
    '72',  -- 初中二年级
    '73'   -- 初中三年级
);

-- 错题状态枚举（含V1.1变更：新增PERMANENTLY_MASTERED）
CREATE TYPE question_status_enum AS ENUM (
    'NOT_STARTED',          -- 未掌握
    'REVIEWING',            -- 复习中
    'MASTERED',             -- 已消灭
    'PERMANENTLY_MASTERED'  -- 永久消灭（通过90天复活检测）
);

-- 错因粗分类枚举（含V1.1变更：新增UNKNOWN）
CREATE TYPE error_category_enum AS ENUM (
    'KNOWLEDGE',   -- 知识性错误
    'SKILL',       -- 技能性错误
    'PSYCHOLOGY',  -- 心理性错误
    'HABIT',       -- 习惯性错误
    'UNKNOWN'      -- 不确定（仅小学生，不计入错因分布统计）
);

-- 自评结果枚举
CREATE TYPE self_rating_enum AS ENUM (
    'MASTERED',  -- 完全掌握
    'PARTIAL',   -- 部分记得
    'FAILED'     -- 完全不会
);

-- 知识点学段枚举
CREATE TYPE stage_enum AS ENUM (
    'PRIMARY',  -- 小学
    'JUNIOR'    -- 初中
);

-- 同步队列操作类型枚举
CREATE TYPE sync_operation_enum AS ENUM (
    'CREATE',  -- 新建
    'UPDATE',  -- 更新
    'DELETE'   -- 删除
);

-- 同步队列状态枚举
CREATE TYPE sync_status_enum AS ENUM (
    'PENDING',   -- 待上传
    'UPLOADING', -- 上传中
    'SUCCESS',   -- 上传成功
    'FAILED'     -- 上传失败（已达最大重试次数）
);

-- 设备类型枚举
CREATE TYPE device_type_enum AS ENUM (
    'IOS',
    'ANDROID'
);

## 3.3 索引设计

```sql
-- ============================================================
-- 索引设计
-- 原则：覆盖高频查询路径，避免过度索引影响写入性能
-- ============================================================

-- ==================== users ====================
-- phone已有UNIQUE约束自动创建索引
CREATE INDEX idx_users_last_active ON users(last_active_at) WHERE deleted_at IS NULL;

-- ==================== questions ====================
-- 核心：按用户+状态筛选错题列表
CREATE INDEX idx_questions_user_status ON questions(user_id, status)
    WHERE deleted_at IS NULL;

-- 核心：获取今日待复习列表（最高频查询！）
CREATE INDEX idx_questions_user_next_review ON questions(user_id, next_review_date)
    WHERE deleted_at IS NULL AND status IN ('NOT_STARTED', 'REVIEWING');

-- 按错因筛选
CREATE INDEX idx_questions_user_category ON questions(user_id, error_category)
    WHERE deleted_at IS NULL;

-- 按录入时间排序/筛选
CREATE INDEX idx_questions_user_created ON questions(user_id, created_at DESC)
    WHERE deleted_at IS NULL;

-- 复活检测队列
CREATE INDEX idx_questions_revive_check ON questions(mastered_at, revive_check_date)
    WHERE deleted_at IS NULL AND status = 'MASTERED';

-- 软删除过期清理定时任务
CREATE INDEX idx_questions_deleted_expired ON questions(deleted_at)
    WHERE deleted_at IS NOT NULL;

-- Dashboard统计聚合
CREATE INDEX idx_questions_user_stats ON questions(user_id, status, error_category)
    WHERE deleted_at IS NULL;

-- ==================== review_records ====================
CREATE INDEX idx_review_user_date ON review_records(user_id, reviewed_at DESC);
CREATE INDEX idx_review_question ON review_records(question_id, reviewed_at DESC);
CREATE INDEX idx_review_user_date_only ON review_records(user_id, (reviewed_at::date));

-- ==================== knowledge_points ====================
CREATE INDEX idx_kp_stage_level ON knowledge_points(stage, level, sort_order);
CREATE INDEX idx_kp_parent ON knowledge_points(parent_id, sort_order);

-- ==================== question_knowledge ====================
-- 按知识点查错题数（薄弱知识点排行）
CREATE INDEX idx_qk_kp ON question_knowledge(knowledge_point_id);
-- 注：联合主键已覆盖按question_id查询

-- ==================== weekly_reports ====================
CREATE INDEX idx_report_user_created ON weekly_reports(user_id, week_number DESC);

-- ==================== sync_queue ====================
CREATE INDEX idx_sync_pending ON sync_queue(user_id, created_at)
    WHERE status IN ('PENDING', 'FAILED') AND next_retry_at <= NOW();
CREATE INDEX idx_sync_user_status ON sync_queue(user_id, status);

-- ==================== user_devices ====================
CREATE INDEX idx_device_user_login ON user_devices(user_id, last_login_at DESC);

## 3.5 数据库设计决策备注

| # | 决策 | 原因 | 替代方案 |
|---|------|------|---------|
| 1 | PostgreSQL原生ENUM | 类型安全，防止非法值写入 | VARCHAR+CHECK |
| 2 | JSONB而非JSON | 支持索引和高效查询内部字段 | JSON/独立关联表 |
| 3 | TIMESTAMPTZ | 避免时区歧义，统一UTC存储 | TIMESTAMP+时区约定 |
| 4 | BIGSERIAL主键 | 分布式友好，避免序列冲突 | UUID（空间开销大） |
| 5 | deleted_at软删除 | 可追溯删除时间，支持30天恢复 | BOOLEAN is_deleted |
| 6 | sync_queue独立建表 | 解耦同步逻辑与业务逻辑 | 业务表加sync_status |
| 7 | user_devices独立建表 | 精确设备管理和踢出逻辑 | Redis缓存设备信息 |
| 8 | revive_check_interval冗余 | 避免每次查询计算递进间隔 | 根据mastered_at动态算 |
| 9 | solution_steps用JSONB数组 | 步骤数量不定，无需独立表 | question_steps表 |
| 10 | weekly_reports冗余prev_week | 避免每次JOIN上一周数据 | 实时JOIN查询 |

```
Authorization: Bearer <JWT_TOKEN>
```

- Token有效期：Access Token 24小时 + Refresh Token 30天自动续期（用户感知有效期30天，FR-001-7）

成功：`{"code": 0, "message": "success", "data": {...}}`

## 5. 艾宾浩斯复习调度引擎

> **对应PRD：** FR-400 艾宾浩斯复习调度引擎、FR-401 每日复习流程
> **MVP范围：** 全部纳入MVP

### 1.1 策略模式接口设计

采用策略模式，将调度算法抽象为可插拔接口，便于后续版本替换或A/B测试不同算法。

```go
// review/scheduler/interface.go
package scheduler

import "time"

type ReviewPlan struct {
    QuestionID     int64
    UserID         int64
    CurrentRound   int       // 当前轮次 1-5
    MasterCount    int       // 消灭计数 0-3
    NextReviewDate time.Time
}

type SelfRating string
const (
    RatingMastered SelfRating = "MASTERED"
    RatingPartial  SelfRating = "PARTIAL"
    RatingFailed   SelfRating = "FAILED"
)

// ScheduleStrategy 调度策略接口（策略模式）
// MVP实现EbbinghausStrategy，V1.1可扩展AdaptiveStrategy
type ScheduleStrategy interface {
    Name() string
    CalcNextReview(plan ReviewPlan, rating SelfRating) (nextDate time.Time, newRound int, newMasterCount int)
    IsCompleted(plan ReviewPlan) bool
    GetIntervalDays(round int) int
}
```

### 1.2 基础调度算法（EbbinghausStrategy）

**5轮间隔表：**

| 轮次 | 间隔天数 | 累计距录入天数 |
|------|---------|--------------|
| 1 | 1 | 1 |
| 2 | 2 | 3 |
| 3 | 4 | 7 |
| 4 | 7 | 14 |
| 5 | 16 | 30 |

```go
// review/scheduler/ebbinghaus.go
package scheduler

import "time"

var EbbinghausIntervals = [5]int{1, 2, 4, 7, 16}

type EbbinghausStrategy struct{}

func (s *EbbinghausStrategy) Name() string { return "ebbinghaus" }

func (s *EbbinghausStrategy) GetIntervalDays(round int) int {
    if round < 1 || round > 5 { return 0 }
    return EbbinghausIntervals[round-1]
}

// CalcNextReview 核心调度逻辑（PRD FR-400）
func (s *EbbinghausStrategy) CalcNextReview(
    plan ReviewPlan, rating SelfRating,
) (nextDate time.Time, newRound int, newMasterCount int) {
    now := time.Now()
    today := time.Date(now.Year(), now.Month(), now.Day(), 0, 0, 0, 0, now.Location())
    switch rating {
    case RatingMastered:
        newMasterCount = plan.MasterCount + 1
        newRound = plan.CurrentRound + 1
        if newRound > 5 { nextDate = time.Time{} } else {
            nextDate = today.AddDate(0, 0, s.GetIntervalDays(newRound))
        }
    case RatingPartial:
        newMasterCount = plan.MasterCount; newRound = plan.CurrentRound
        nextDate = today.AddDate(0, 0, s.GetIntervalDays(newRound))
    case RatingFailed:
        newMasterCount = 0; newRound = 1
        nextDate = today.AddDate(0, 0, s.GetIntervalDays(1))
    default:
        newMasterCount = plan.MasterCount; newRound = plan.CurrentRound
        nextDate = today.AddDate(0, 0, s.GetIntervalDays(newRound))
    }
    return
}

// IsCompleted 判断是否满足消灭条件（PRD FR-500-2）
func (s *EbbinghausStrategy) IsCompleted(plan ReviewPlan) bool {
    return plan.CurrentRound > 5 && plan.MasterCount >= 3
}
```

### 1.3 master_count 计算逻辑详解

| 自评结果 | master_count变化 | 说明 |
|---------|-----------------|------|
| MASTERED | +1 | >=3即触发消灭 |
| PARTIAL | 不变 | 中断连续计数但不归零 |
| FAILED | 归零 | 重置为0 |

> UI层不展示master_count具体数值（PRD FR-702-3），仅展示复习轮次进度条。

### 1.4 每日上限20道的顺延算法

**规则来源：** PRD FR-400-4

```go
// review/scheduler/daily_limit.go
package scheduler

import "sort"

const DefaultDailyLimit = 20

type ReviewCandidate struct {
    QuestionID     int64
    ReviewRound    int
    IntervalDays   int
    CreatedAt      int64
    NextReviewDate string
}

// ApplyDailyLimit 优先级：轮次高 > 间隔长 > 录入早
func ApplyDailyLimit(candidates []ReviewCandidate, limit int) (today, deferred []ReviewCandidate) {
    sort.Slice(candidates, func(i, j int) bool {
        a, b := candidates[i], candidates[j]
        if a.ReviewRound != b.ReviewRound { return a.ReviewRound > b.ReviewRound }
        if a.IntervalDays != b.IntervalDays { return a.IntervalDays > b.IntervalDays }
        return a.CreatedAt < b.CreatedAt
    })
    if len(candidates) <= limit { return candidates, nil }
    return candidates[:limit], candidates[limit:]
}
```

### 1.6 定时任务设计

**触发时间：** 每天凌晨 00:00
**幂等性保证：** Redis SETNX 防重入

```go
// review/cron/daily_scheduler.go
package cron

import ("context"; "fmt"; "log"; "time"; "errorhunter/review/scheduler")

// DailyScheduleJob Cron: 0 0 0 * * *
func DailyScheduleJob(ctx context.Context, svc *SchedulerService) error {
    today := time.Now().Format("2006-01-02")
    idempotentKey := fmt.Sprintf("daily_schedule:%s", today)

    acquired, err := svc.redis.SetNX(ctx, idempotentKey, 1, 25*time.Hour).Result()
    if err != nil { return fmt.Errorf("acquire lock: %w", err) }
    if !acquired { log.Printf("[DailySchedule] skip %s", today); return nil }

    batchSize := 100; lastUserID := int64(0)
    for {
        users, err := svc.userRepo.GetActiveUsersBatch(ctx, lastUserID, batchSize)
        if err != nil { return err }
        if len(users) == 0 { break }
        for _, user := range users {
            if err := svc.scheduleForUser(ctx, user.ID, today); err != nil {
                log.Printf("[DailySchedule] user %d failed: %v", user.ID, err)
            }
        }
        lastUserID = users[len(users)-1].ID
    }
    return nil
}

func (svc *SchedulerService) scheduleForUser(ctx context.Context, userID int64, today string) error {
    candidates, _ := svc.questionRepo.GetDueQuestions(ctx, userID, today)
    limit := svc.getUserDailyLimit(ctx, userID)
    todayList, deferred := scheduler.ApplyDailyLimit(candidates, limit)

    cacheKey := fmt.Sprintf("review_plan:%s:%d", today, userID)
    svc.redis.Set(ctx, cacheKey, todayList, 48*time.Hour)

    totalPending := len(candidates) + svc.getDeferredCount(ctx, userID)
    if totalPending > scheduler.BacklogThreshold {
        sorted := scheduler.SortBacklog(convertToBacklogCandidates(candidates))
        svc.redis.Set(ctx, cacheKey+":backlog", sorted, 48*time.Hour)
    }
    for _, d := range deferred { svc.questionRepo.DeferQuestion(ctx, d.QuestionID, today) }
    return nil
}
```

## 6. 消灭引擎

> **对应PRD：** FR-500 消灭机制、FR-601 消灭动画
> **MVP范围：** 全部纳入MVP（含复活检测降频+永久消灭）

### 2.1 完整状态机设计

```
NOT_STARTED --[首次复习]--> REVIEWING --[master_count>=3]--> MASTERED
                                ^                               |
                                |                               |--[30天通过]--> MASTERED(下次60天)
                                |                               |--[60天通过]--> MASTERED(下次90天)
                                |                               |--[90天通过]--> PERMANENTLY_MASTERED
                                |                               |--[检测失败]--> REVIEWING(count归零)
                                +--[自评任意结果，循环复习]------+
```

### 2.2 状态转换条件表

| 当前状态 | 触发事件 | 目标状态 | 附加动作 | 来源 |
|---------|---------|---------|---------|------|
| NOT_STARTED | 首次复习 | REVIEWING | 记录review_record | FR-500-1 |
| REVIEWING | MASTERED且count<3 | REVIEWING | count+1, 算下次复习日 | FR-500-2a |
| REVIEWING | PARTIAL | REVIEWING | count不变, 重复当前轮次 | FR-500-2b |

// review/extinction/revive_checker.go
package extinction

import ("context"; "fmt"; "time")

var ReviveIntervals = []int{30, 60, 90}

type ReviveCheckStatus string
const (
    ReviveRemembered ReviveCheckStatus = "REMEMBERED"
    ReviveForgotten  ReviveCheckStatus = "FORGOTTEN"
)

type QuestionExtinctionService struct {
    questionRepo QuestionRepository
    redis        RedisClient
    eventBus     EventBus
}

// GetReviveQueue mastered_at最早的优先，每日最多3道
func (s *QuestionExtinctionService) GetReviveQueue(
    ctx context.Context, userID int64, today time.Time,
) ([]ReviveCandidate, error) {
    const dailyReviveLimit = 3
    candidates, err := s.questionRepo.GetReviveCandidates(ctx, userID, today, dailyReviveLimit)
    if err != nil { return nil, fmt.Errorf("get revive candidates: %w", err) }
    result := make([]ReviveCandidate, 0, len(candidates))
    for _, c := range candidates {
        result = append(result, ReviveCandidate{
            QuestionID: c.ID, MasteredAt: c.MasteredAt,
            CurrentInterval: c.ReviveInterval, ImageURL: c.ImageURL,
            OcrText: c.OcrText, IsReviveCheck: true,
        })
    }
    return result, nil
}

func (s *QuestionExtinctionService) ProcessReviveResult(
    ctx context.Context, questionID int64, userID int64, status ReviveCheckStatus,
) error {
    q, err := s.questionRepo.GetByID(ctx, questionID)
    if err != nil { return err }
    switch status {
    case ReviveRemembered:
        nextInterval := getNextReviveInterval(q.ReviveInterval)
        if nextInterval == 0 { return s.markPermanentlyMastered(ctx, q) }
        nextDate := time.Now().AddDate(0, 0, nextInterval)
        return s.questionRepo.UpdateReviveSchedule(ctx, questionID, nextInterval, nextDate)
    case ReviveForgotten:
        return s.reviveFailed(ctx, q)
    }
    return nil
}

// getNextReviveInterval 30->60->90->0(永久消灭)
func getNextReviveInterval(current int) int {
    for i, v := range ReviveIntervals {
        if current == v {
            if i+1 < len(ReviveIntervals) { return ReviveIntervals[i+1] }
            return 0
        }
    }
    return 0
}

func (s *QuestionExtinctionService) markPermanentlyMastered(ctx context.Context, q *Question) error {
    if err := s.questionRepo.UpdateStatus(ctx, q.ID, "PERMANENTLY_MASTERED"); err != nil { return err }
    s.eventBus.Publish(ctx, "question.permanently_mastered", map[string]interface{}{"question_id": q.ID, "user_id": q.UserID})
    return nil
}

func (s *QuestionExtinctionService) reviveFailed(ctx context.Context, q *Question) error {
    if err := s.questionRepo.ReactivateQuestion(ctx, q.ID); err != nil { return err }
    strategy := &scheduler.EbbinghausStrategy{}
    nextDate := time.Now().AddDate(0, 0, strategy.GetIntervalDays(1))
    if err := s.questionRepo.ResetReviewPlan(ctx, q.ID, nextDate); err != nil { return err }
    // 鼓励式文案，不使用"复活"字样（PRD FR-500-4f）
    s.eventBus.Publish(ctx, "question.revive_failed", map[string]interface{}{
        "question_id": q.ID, "user_id": q.UserID, "message": "这道题需要再巩固一下哦！",
    })
    return nil
}

// review/extinction/state_machine.go
package extinction

import "fmt"

type QuestionStatus string
const (
    StatusNotStarted          QuestionStatus = "NOT_STARTED"
    StatusReviewing           QuestionStatus = "REVIEWING"
    StatusMastered            QuestionStatus = "MASTERED"
    StatusPermanentlyMastered QuestionStatus = "PERMANENTLY_MASTERED"
)

type Transition struct {
    From   QuestionStatus
    Event  string
    To     QuestionStatus
    Guard  func(ctx *TransitionContext) bool
    Action func(ctx *TransitionContext) error
}

type TransitionContext struct {
    QuestionID   int64
    UserID       int64
    MasterCount  int
    SelfRating   string
    ReviveResult string
}

type StateMachine struct{ transitions []Transition }

func NewStateMachine() *StateMachine {
    sm := &StateMachine{}
    sm.transitions = []Transition{
        {From: StatusNotStarted, Event: "first_review", To: StatusReviewing,
         Guard: func(ctx *TransitionContext) bool { return true }},
        {From: StatusReviewing, Event: "review_continue", To: StatusReviewing,
         Guard: func(ctx *TransitionContext) bool { return ctx.MasterCount < 3 }},
        {From: StatusReviewing, Event: "master", To: StatusMastered,
         Guard: func(ctx *TransitionContext) bool { return ctx.MasterCount >= 3 }},
        {From: StatusMastered, Event: "permanent_master", To: StatusPermanentlyMastered,
         Guard: func(ctx *TransitionContext) bool { return ctx.ReviveResult == "passed_90d" }},
        {From: StatusMastered, Event: "revive_failed", To: StatusReviewing,
         Guard: func(ctx *TransitionContext) bool { return ctx.ReviveResult == "forgotten" }},
    }
    return sm
}

func (sm *StateMachine) CanTransition(from QuestionStatus, event string, ctx *TransitionContext) bool {
    for _, t := range sm.transitions {
        if t.From == from && t.Event == event && (t.Guard == nil || t.Guard(ctx)) { return true }
    }
    return false
}

func (sm *StateMachine) Transition(from QuestionStatus, event string, ctx *TransitionContext) (QuestionStatus, error) {
    for _, t := range sm.transitions {
        if t.From == from && t.Event == event {
            if t.Guard != nil && !t.Guard(ctx) {
                return from, fmt.Errorf("guard not met: %s->%s", from, event)
            }
            if t.Action != nil {
                if err := t.Action(ctx); err != nil { return from, fmt.Errorf("action failed: %w", err) }
            }
            return t.To, nil
        }
    }
    return from, fmt.Errorf("no transition: %s + %s", from, event)
}

const OCRTimeout = 5 * time.Second

type OCRResult struct {
    Text           string  `json:"text"`
    Confidence     float64 `json:"confidence"`
    HasHandwriting bool    `json:"has_handwriting"`
    HasFormula     bool    `json:"has_formula"`
    Degraded       bool    `json:"degraded"`
    DegradeReason  string  `json:"degrade_reason"`
}

func (s *OCRService) Recognize(ctx context.Context, imageURL string) (*OCRResult, error) {
    timeoutCtx, cancel := context.WithTimeout(ctx, OCRTimeout)
    defer cancel()
    resultCh := make(chan *OCRResult, 1)
    errCh := make(chan error, 1)
    go func() {
        r, e := s.provider.Recognize(timeoutCtx, imageURL)
        if e != nil { errCh <- e; return }
        resultCh <- r
    }()
    select {
    case r := <-resultCh: return r, nil
    case e := <-errCh:
        log.Printf("[OCR] failed: %v", e)
        return &OCRResult{Degraded: true, DegradeReason: fmt.Sprintf("识别失败: %v", e)}, nil
    case <-timeoutCtx.Done():
        log.Printf("[OCR] timeout %v", OCRTimeout)
        return &OCRResult{Degraded: true, DegradeReason: "识别超时，请手动输入题目内容"}, nil
    }
}

var FormulaPatterns = []*regexp.Regexp{
    regexp.MustCompile(`[+\-*\/=<>]+\s*\d`),
    regexp.MustCompile(`\frac\{.*?\}\{.*?\}`),

    r := rawText
    for o, n := range repl { r = strings.ReplaceAll(r, o, n) }
    return r
}

package sync

import ("math"; "time")

const (MaxRetryCount = 3; BaseDelay = 1 * time.Second)

// CalcRetryDelay 指数退避: 1s -> 2s -> 4s
func CalcRetryDelay(retryCount int) time.Duration {
    if retryCount >= MaxRetryCount { return 0 }
    return BaseDelay * time.Duration(math.Pow(2, float64(retryCount)))
}
func ShouldRetry(retryCount int) bool { return retryCount < MaxRetryCount }

### 5.2 Go代码实现

```go
// knowledge/recommender/keyword_matcher.go
package recommender

import ("context"; "sort"; "strings"; "github.com/go-ego/gse")

type KnowledgePointWithKeywords struct {
    ID       int      `json:"id"`
    Name     string   `json:"name"`
    Stage    string   `json:"stage"`    // PRIMARY / JUNIOR
    Keywords []string `json:"keywords"`
}

type RecommendResult struct {
    KnowledgePointID int     `json:"knowledge_point_id"`
    Name             string  `json:"name"`
    Score            float64 `json:"score"`
    IsAIRecommended  bool    `json:"is_ai_recommended"`
}

type KeywordMatcher struct {
    seg       gse.Segmenter  // V1.1修订：原gojieba替换为gse（纯Go，无CGO依赖）
    cache     KnowledgeCache
    stopWords map[string]bool
}

func NewKeywordMatcher(cache KnowledgeCache) *KeywordMatcher {
    var seg gse.Segmenter
    seg.LoadDict("/dict/zh")  // 纯Go字典加载，Docker镜像需COPY dict/
    return &KeywordMatcher{seg: seg, cache: cache, stopWords: loadStopWords()}
}

func (m *KeywordMatcher) Recommend(ctx context.Context, text string, stage string, topN int) ([]RecommendResult, error) {
    words := m.extractKeywords(preprocess(text))
    kps, err := m.cache.GetKnowledgePoints(ctx, stage)
    if err != nil { return nil, err }
    var results []RecommendResult
    for _, kp := range kps {
        score := m.calcMatchScore(words, kp.Keywords)
        if score > 0.3 {
            results = append(results, RecommendResult{kp.ID, kp.Name, score, true})
        }
    }
    sort.Slice(results, func(i, j int) bool { return results[i].Score > results[j].Score })
    if len(results) > topN { results = results[:topN] }
    return results, nil
}

func (m *KeywordMatcher) extractKeywords(text string) []string {
    tags := m.jieba.Tag(text)
    var kw []string
    for _, tag := range tags {
        if isContentWord(tag.Pos) && !m.stopWords[tag.Word] && len(tag.Word) >= 2 {
            kw = append(kw, tag.Word)
        }
    }
    return kw
}

// calcMatchScore: score = 命中关键词数 / 知识点总关键词数
func (m *KeywordMatcher) calcMatchScore(textWords, kpKeywords []string) float64 {
    if len(kpKeywords) == 0 { return 0 }
    ws := make(map[string]bool, len(textWords))
    for _, w := range textWords { ws[w] = true }
    hits := 0
    for _, kw := range kpKeywords {
        if ws[kw] { hits++; continue }
        for tw := range ws {
            if strings.Contains(tw, kw) || strings.Contains(kw, tw) { hits++; break }
        }
    }
    return float64(hits) / float64(len(kpKeywords))
}

func isContentWord(pos string) bool {
    m := map[string]bool{"n":true,"nr":true,"ns":true,"nt":true,"v":true,"vn":true,"m":true,"nz":true}
    return m[pos]
}

func preprocess(text string) string {
    text = removeDigits(text)
    text = fullWidthToHalfWidth(text)
    return strings.TrimSpace(text)
}

func (s *DashboardService) GetDashboard(ctx context.Context, userID int64) (*DashboardData, error) {
    today := time.Now().Format("2006-01-02")

    // 1. 今日待复习数 -> 实时Redis LLen
    pendingKey := fmt.Sprintf("review_plan:%s:%d", today, userID)
    pendingCount, _ := s.redis.LLen(ctx, pendingKey).Result()

    statsKey := fmt.Sprintf("dashboard_stats:%s:%d", today, userID)

        if json.Unmarshal([]byte(cached), &data) == nil {
            data.TodayPendingCount = int(pendingCount)
            return &data, nil
        }
    }

    // 3. Redis miss -> DB预计算表（兜底查昨日）
    stats, err := s.statsRepo.GetDailyStats(ctx, userID, today)
    if err != nil {
        yesterday := time.Now().AddDate(0, 0, -1).Format("2006-01-02")
        stats, err = s.statsRepo.GetDailyStats(ctx, userID, yesterday)
        if err != nil { return nil, err }
    }

    data := convertToDashboardData(stats)
    data.TodayPendingCount = int(pendingCount)
    jsonData, _ := json.Marshal(data)
    s.redis.Set(ctx, statsKey, string(jsonData), 6*time.Hour)

### 6.3 周报生成算法（每周日20:00定时任务）

> **V1.1 修订：** 原逐用户循环查询改为聚合SQL + 分批执行，解决万级用户下7万次DB查询的性能问题。

```go
// stats/weekly_report_generator.go
package stats

import ("context"; "time"; "log"; "fmt")

type WeeklyReportData struct {
    WeekNumber        int       `json:"week_number"` // 如202624
    WeekStart         time.Time `json:"week_start"`
    WeekEnd           time.Time `json:"week_end"`
    NewQuestions      int       `json:"new_questions"`
    MasteredQuestions int       `json:"mastered_questions"`
    ReviewCount       int       `json:"review_count"`
    ReviewAccuracy    float64   `json:"review_accuracy"`
    PrevWeekNew       int       `json:"prev_week_new"`
    PrevWeekMastered  int       `json:"prev_week_mastered"`
    TopErrorCategory  string    `json:"top_error_category"`
    WeakKnowledgeTop  []WeakKP  `json:"weak_knowledge_top"`
}

const batchLimit = 1000
const batchSleepInterval = 100 * time.Millisecond

func (g *ReportGenerator) GenerateWeeklyReportBatch(ctx context.Context, weekStart time.Time) error {
    weekEnd := weekStart.AddDate(0, 0, 6)
    year, weekNum := weekStart.ISOWeek()
    weekNumber := year*100 + weekNum

    // 幂等性：ON CONFLICT DO NOTHING 保证重复执行不产生重复数据
    lastUserID := int64(0)
    totalProcessed := 0
    totalFailed := 0

    for {
        // 聚合SQL：一次查询一批用户的周报数据
        sql := `
        INSERT INTO weekly_reports (
            user_id, week_number, week_start, week_end,
            new_questions, mastered_questions, review_count, review_accuracy,
            prev_week_new, prev_week_mastered, top_error_category, weak_knowledge_top, created_at
        )
        SELECT
            q.user_id, $1, $2, $3,
            COUNT(*) FILTER (WHERE q.created_at BETWEEN $2 AND $3 AND q.deleted_at IS NULL),
            COUNT(*) FILTER (WHERE q.mastered_at BETWEEN $2 AND $3 AND q.deleted_at IS NULL),
            -- review_stats via subquery
            COALESCE((SELECT COUNT(*) FROM review_records rr
                      WHERE rr.user_id = q.user_id AND rr.reviewed_at BETWEEN $2 AND $3), 0),
            COALESCE((SELECT COUNT(*) FILTER (WHERE rr2.self_rating='MASTERED')::numeric * 100.0
                      / NULLIF(COUNT(*), 0) FROM review_records rr2
                      WHERE rr2.user_id = q.user_id AND rr2.reviewed_at BETWEEN $2 AND $3), 0),
            -- prev week stats
            0, 0,  -- 简化：prev_week数据在后续SELECT中补充
            -- top error category
            (SELECT mode() WITHIN GROUP (ORDER BY q2.error_category)
             FROM questions q2 WHERE q2.user_id = q.user_id AND q2.deleted_at IS NULL),
            '[]'::jsonb,  -- weak_knowledge_top via separate query
            NOW()
        FROM questions q
        WHERE q.user_id > $4 AND q.deleted_at IS NULL
        GROUP BY q.user_id
        ORDER BY q.user_id
        LIMIT $5
        ON CONFLICT (user_id, week_number) DO NOTHING;
        `
        result, err := g.db.Exec(ctx, sql, weekNumber, weekStart, weekEnd, lastUserID, batchLimit)
        if err != nil {
            log.Printf("[WeeklyReport] batch error after user %d: %v", lastUserID, err)
            totalFailed++
            // 继续下一批，不阻塞整体流程
        }
        rowsAffected, _ := result.RowsAffected()
        totalProcessed += int(rowsAffected)

        // 检查是否还有更多用户
        if rowsAffected < int64(batchLimit) {
            break  // 最后一批
        }

        // 获取最后一批的最大user_id作为下一批起点
        lastUserID, _ = g.getLastProcessedUserID(ctx, weekStart, weekEnd, lastUserID, batchLimit)

        // 更新进度指标
        g.metrics.WeeklyReportProgress.WithLabelValues("processed").Set(float64(totalProcessed))
        g.metrics.WeeklyReportProgress.WithLabelValues("failed").Set(float64(totalFailed))

        // 批间休眠，避免DB压力过大
        time.Sleep(batchSleepInterval)
    }

    log.Printf("[WeeklyReport] completed: processed=%d, failed=%d", totalProcessed, totalFailed)
    return nil
}
```

// internal/module/auth/jwt.go
package auth

import (
	"context"
	"fmt"
	"time"
	"github.com/golang-jwt/jwt/v5"
	"github.com/google/uuid"
)

type Claims struct {
	jwt.RegisteredClaims
	UserID   int64  `json:"uid"`
	DeviceID string `json:"did"`
	Grade    int    `json:"grade"`
}

type TokenPair struct {
	AccessToken  string `json:"access_token"`
	RefreshToken string `json:"refresh_token"`
	ExpiresIn    int64  `json:"expires_in"`
}

const (
	accessTokenTTL  = 24 * time.Hour  // V1.1修订：原2h延长至24h，防止复习进行中Token过期
	refreshTokenTTL = 30 * 24 * time.Hour
)

func (s *AuthService) GenerateTokenPair(ctx context.Context, userID int64, deviceID string, grade int) (*TokenPair, error) {
	now := time.Now()
	jti := uuid.New().String()
	accessClaims := Claims{
		RegisteredClaims: jwt.RegisteredClaims{
			ID: jti, Subject: fmt.Sprintf("%d", userID),
			IssuedAt: jwt.NewNumericDate(now), ExpiresAt: jwt.NewNumericDate(now.Add(accessTokenTTL)),
			Issuer: "errorhunter",
		},
		UserID: userID, DeviceID: deviceID, Grade: grade,
	}
	accessToken, _ := jwt.NewWithClaims(jwt.SigningMethodHS256, accessClaims).SignedString([]byte(s.cfg.JWTSecret))

	refreshJTI := uuid.New().String()
	refreshClaims := Claims{
		RegisteredClaims: jwt.RegisteredClaims{
			ID: refreshJTI, Subject: fmt.Sprintf("%d", userID),
			IssuedAt: jwt.NewNumericDate(now), ExpiresAt: jwt.NewNumericDate(now.Add(refreshTokenTTL)),
			Issuer: "errorhunter",
		},
		UserID: userID, DeviceID: deviceID,
	}
	refreshToken, _ := jwt.NewWithClaims(jwt.SigningMethodHS256, refreshClaims).SignedString([]byte(s.cfg.JWTRefreshSecret))

	return &TokenPair{AccessToken: accessToken, RefreshToken: refreshToken, ExpiresIn: int64(accessTokenTTL.Seconds())}, nil
}

func (s *AuthService) ValidateAccessToken(ctx context.Context, tokenStr string) (*Claims, error) {
	token, err := jwt.ParseWithClaims(tokenStr, &Claims{}, func(t *jwt.Token) (interface{}, error) {
		if _, ok := t.Method.(*jwt.SigningMethodHMAC); !ok {
			return nil, fmt.Errorf("unexpected signing method: %v", t.Header["alg"])
		}
		return []byte(s.cfg.JWTSecret), nil
	})
	if err != nil { return nil, err }
	claims, ok := token.Claims.(*Claims)
	if !ok || !token.Valid { return nil, fmt.Errorf("invalid claims") }

	// 检查黑名单（主动失效/踢设备）
	exists, _ := s.redis.Exists(ctx, fmt.Sprintf("jwt:blacklist:%s", claims.ID)).Result()
	if exists > 0 { return nil, fmt.Errorf("token revoked") }
	return claims, nil
}

func (s *AuthService) RevokeToken(ctx context.Context, jti string, remainingTTL time.Duration) error {
	return s.redis.Set(ctx, fmt.Sprintf("jwt:blacklist:%s", jti), "1", remainingTTL).Err()
}
```

### 3.2 多设备登录管理（FR-001-5/6）

规则：最多3台设备，第4台踢最早登录的设备。被踢设备收到401 TOKEN_REVOKED提示重新登录。

```go
// internal/module/auth/device.go
const maxDevicesPerUser = 3

type DeviceSession struct {
	DeviceID   string    `json:"device_id"`
	DeviceName string    `json:"device_name"`
	JTI        string    `json:"jti"`
	LoginAt    time.Time `json:"login_at"`
	Platform   string    `json:"platform"`
}

func (s *AuthService) RegisterDevice(ctx context.Context, userID int64, session DeviceSession) ([]string, error) {
	// V1.1修订：改用Redis HASH替代KEYS命令，避免O(N)全keyspace扫描
	sessionKey := fmt.Sprintf("session:%d", userID)
	allDevices, err := s.redis.HGetAll(ctx, sessionKey).Result()
	if err != nil {
		return nil, fmt.Errorf("查询设备列表失败: %w", err)  // V1.1: 不再忽略错误
	}

	type entry struct { deviceID string; session DeviceSession }
	var entries []entry
	for did, data := range allDevices {
		var ds DeviceSession
		if json.Unmarshal([]byte(data), &ds) != nil { continue }
		entries = append(entries, entry{deviceID: did, session: ds})
	}
	// 按登录时间升序（最早的在前）
	sort.Slice(entries, func(i, j int) bool {
		return entries[i].session.LoginAt.Before(entries[j].session.LoginAt)
	})

	var evictedJTIs []string
	for len(entries) >= maxDevicesPerUser {
		victim := entries[0]; entries = entries[1:]
		remainingTTL := time.Until(victim.session.LoginAt.Add(refreshTokenTTL))
		if remainingTTL > 0 { _ = s.RevokeToken(ctx, victim.session.JTI, remainingTTL) }
		_ = s.redis.HDel(ctx, sessionKey, victim.deviceID).Err()
		evictedJTIs = append(evictedJTIs, victim.session.JTI)
	}

	data, _ := json.Marshal(session)
	s.redis.HSet(ctx, sessionKey, session.DeviceID, string(data))
	return evictedJTIs, nil
}
```

#### 防击穿实现（singleflight）

```go
var sf singleflight.Group

func GetOrLoad[T any](ctx context.Context, key string, ttl time.Duration,
	loadFn func(ctx context.Context) (T, error),
	getter func(ctx context.Context, key string) (T, bool),
	setter func(ctx context.Context, key string, val T, ttl time.Duration),
) (T, error) {
	if val, ok := getter(ctx, key); ok { return val, nil }
	result, err, _ := sf.Do(key, func() (interface{}, error) {
		if val, ok := getter(ctx, key); ok { return val, nil } // double-check
		val, err := loadFn(ctx)
		if err != nil { var zero T; return zero, err }
		setter(ctx, key, val, ttl)
		return val, nil
	})
	if err != nil { var zero T; return zero, err }
	return result.(T), nil
}
```

**雪崩防护：** jitterTTL在base上添加+-10%随机偏移。

### 4.5 首页Dashboard加载优化

四重策略组合：

1. **离线预计算（FR-600-2）**：每天00:00定时任务聚合统计数据写入Redis
2. **Redis缓存**：API优先读缓存(TTL到次日00:00)，miss回源
3. **客户端懒加载**：首屏(<200ms)->二屏(骨架屏异步)->三屏(视口触发)

```go
func (s *ReportService) ComputeDailyDashboard(ctx context.Context) error {
	date := time.Now().Format("2006-01-02")
	userIDs, _ := s.repo.GetActiveUserIDs(ctx, 30)
	for _, uid := range userIDs {
		summary, err := s.aggregateDashboard(ctx, uid)
		if err != nil { continue }
		key := fmt.Sprintf("dashboard:%d:%s", uid, date)
		data, _ := json.Marshal(summary)
		ttl := time.Until(time.Now().AddDate(0, 0, 1).Truncate(24 * time.Hour))
		s.redis.Set(ctx, key, data, ttl)
	}
	return nil
}

### 5.4a 健康检查设计（V1.1 新增）

> **背景：** 原单一 `/api/v1/health` 只检查 Go 进程存活，DB/Redis 挂了仍返回 200，SLB 不会摘除故障节点。

**分离 liveness / readiness probe：**

| 端点 | 检查内容 | 失败行为 | SLB/K8s 配置 |
|------|---------|---------|-------------|
| `/health/live` | Go 进程存活（返回 200） | 进程不可用 | livenessProbe → 重启容器 |
| `/health/ready` | DB ping + Redis ping | 依赖不可用 | readinessProbe → 摘除流量 |

```go
// internal/handler/health.go
package handler

import ("net/http"; "github.com/gin-gonic/gin")

type HealthHandler struct {
    db    *gorm.DB
    redis *redis.Client
}

// Liveness — 仅检查进程存活
func (h *HealthHandler) Live(c *gin.Context) {
    c.JSON(200, gin.H{"status": "ok"})
}

// Readiness — 检查 DB + Redis 连通性
func (h *HealthHandler) Ready(c *gin.Context) {
    ctx := c.Request.Context()

    if err := h.db.WithContext(ctx).Exec("SELECT 1").Error; err != nil {
        c.JSON(503, gin.H{"status": "not_ready", "db": "unreachable", "error": err.Error()})
        return
    }
    if err := h.redis.Ping(ctx).Err(); err != nil {
        c.JSON(503, gin.H{"status": "not_ready", "redis": "unreachable", "error": err.Error()})
        return
    }
    c.JSON(200, gin.H{"status": "ready"})
}
```

**路由注册：**
```go
health := r.Group("/health")
health.GET("/live", healthHandler.Live)
health.GET("/ready", healthHandler.Ready)
```

> **注意：** `/health/*` 路径不走 JWT 中间件，不需要认证。

## 15.3 错误码使用规范

| 规则 | 说明 |
|------|------|
| 唯一性 | 每个错误码全局唯一，不跨模块复用 |
| 可扩展 | 各模块预留空位，新增递增分配 |
| HTTP映射 | 每个错误码绑定默认HTTP状态码 |
| 客户端处理 | 按code判断逻辑，message仅展示 |
| 国际化预留 | message后续可替换为i18n key |
| 日志记录 | 服务端记完整错误码+上下文 |
| 敏感信息 | 不暴露DB字段名、SQL、内部路径 |
