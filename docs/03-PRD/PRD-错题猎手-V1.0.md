## 1. 产品概述

### 1.1 产品定位

**错题猎手**是一款面向**小学 3-6 年级**和**初中**学生的错题管理工具，帮助学生完成错题的 **采集 → 归因 → 复习 → 消灭** 全生命周期管理。

> **命名释义**：学生化身"猎手"，错题是待消灭的"猎物"——传递主动出击、消灭错题的产品态度。

### 1.2 产品核心价值

| 价值点 | 描述 |
|--------|------|
| 高效归档 | 拍照一键录入，告别手抄错题本 |
| 精准归因 | 错因标签 + 知识点关联，找到真正的薄弱点 |
| 科学复习 | 基于艾宾浩斯遗忘曲线的智能复习调度 |
| 可视成长 | 学情报告让进步看得见 |

### 1.3 MVP 范围定义

**MVP 包含（V1.0）：**

- 数学单科（小学 + 初中）
- 拍照录入 + OCR（印刷体 + 去手写能力评估）
- 错因标签（粗分类必填 + 细分类选填 + 小学生"不确定"选项）
- 知识点关联（预置课标知识点树，AI规则匹配推荐）
- 艾宾浩斯复习调度引擎（含递进降频复活检测）
- 卡片式遮挡重做 + 自评
- 错题状态管理（未掌握/复习中/已消灭/永久消灭）
- 基础学情统计（错题数/消灭数/错因分布/薄弱知识点）
- 复习提醒推送
- 消灭动画 + 连续打卡展示 + 消灭进度可视化（复习轮次进度条）
- 简版PDF导出（图片拼接 + 时间范围筛选，客户端本地生成）
- 离线单向上传（本地缓存 + 联网自动同步）
- 数据埋点（Firebase Analytics，北极星指标实时监控）

**MVP 不包含：**

- 语文/英语/物理/化学等其他学科 (V1.1)
- 手写体 OCR 识别 (V1.1)
- AI 深度错因分析（大模型推理） (V1.1)
- AI 举一反三推荐同类题 (V1.1)
- 微信小程序家长端 (V2.0)
- 老师端 / 班级管理 (V2.0)
- 成就徽章 / 宠物养成等深度激励 (V1.1)
- 错题相似度检测（去重） (V1.1)
- 高级组卷打印（智能排版+多题混排） (V1.1)（简版PDF导出已纳入MVP）
- 多设备双向同步 (V1.1)（MVP为单向上传）
- OCR双源主备切换 (V1.1)（MVP为单源）
- 消灭动画自定义风格 (V1.1)（MVP为单一动画）
- 社交功能（PK/排行） (V2.0)

### 1.4 成功指标

| 指标 | 目标值 | 统计口径 |
|------|--------|---------|
| 7 日留存率 | >= 45% | 注册后第 7 日回访 |
| 30 日留存率 | >= 25% | 注册后第 30 日回访 |
| 周活跃率（WAU/MAU） | >= 50% | 自然周 |
| 日均复习完成率 | >= 70% | 每日完成复习数 / 每日待复习数 |
| 错题消灭率 | >= 40% | 已消灭数 / 累计错题数（用户平均） |

## 5. 功能需求详细说明

### 5.1 用户注册与登录

#### FR-100 注册流程

**功能描述：** 新用户通过手机号注册账号。

**前置条件：** 用户已安装 APP，处于未登录状态。

**页面流程：** 手机号输入 -> 获取验证码 -> 输入验证码 -> 选择年级 -> 勾选家长同意 -> 注册成功 -> 进入首页

**字段定义：**

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|---------|
| 手机号 | 数字 | 是 | 11位中国大陆手机号 |
| 验证码 | 数字 | 是 | 6位数字，5分钟有效，60秒发送间隔 |
| 年级 | 枚举 | 是 | 小学3年级/小学4年级/小学5年级/小学6年级/初中1年级/初中2年级/初中3年级 |
| 家长同意 | 布尔 | 是 | 必须勾选才能提交 |
| 昵称 | 文字 | 否 | 2-12个字符，不填则系统默认生成"同学+手机后4位" |

**业务规则：**

| 编号 | 规则 |
|------|------|
| FR-100-1 | 验证码每日同一手机号最多发送 10 次 |
| FR-100-2 | 验证码 5 分钟过期 |
| FR-100-3 | 验证码连续输错 5 次，锁定 30 分钟 |
| FR-100-4 | 年级选择后进入首页，年级信息用于：a) 匹配对应学段知识点树 b) 决定 UI 风格倾向（后续版本） |
| FR-100-5 | 年级信息后续可在"我的"中修改 |
| FR-100-6 | 注册成功后自动登录，Token 有效期 30 天 |

**异常处理：**

| 异常场景 | 处理方式 |
|---------|---------|
| 手机号已注册 | 提示"该手机号已注册，是否直接登录？"，点击跳转登录 |
| 验证码过期 | 提示"验证码已过期，请重新获取" |
| 网络中断 | 提示"网络连接失败，请检查网络" |

#### FR-101 登录流程

| 编号 | 规则 |
|------|------|
| FR-101-1 | 登录方式：手机号 + 验证码（与注册共用流程） |
| FR-101-2 | 自动登录：上次登录未超 30 天，打开 APP 直接进入首页 |
| FR-101-3 | Token 过期：引导重新登录，不丢失本地离线数据 |

### 5.2 错题采集

#### FR-200 拍照录入（核心流程）

**功能描述：** 用户通过拍照或从相册选择图片，系统识别题目内容并完成录入。

**设计原则：** 系统多做，用户少做。AI 推荐 + 用户确认/修改。

**三步录入流程：**

**第1步：拍照/选图**
- 用户操作：点击录入按钮 -> 选择"拍照"或"从相册选择"
- 系统自动：a) 智能裁剪题目区域（支持手动调整裁剪框） b) OCR 识别题目文字（仅印刷体） c) 保存原始图片

**第2步：确认信息**
- 页面展示：题目图片（可放大查看）、OCR 识别出的文字（可编辑修改）、我的错误答案（选填）、正确答案（选填）、AI 推荐的错因标签（可修改）、AI 推荐的知识点标签（可修改）
- 用户操作：确认/修改以上信息

**第3步：选择错因并保存**
- 必选：错因粗分类（4选1，不可跳过）
- 选填：错因细分类（可跳过）
- 选填：自定义标签
- 用户操作：选错因 -> 点击"保存并加入复习计划"
- 录入成功，自动加入艾宾浩斯复习计划，第1次复习时间：明天

**业务规则：**

| 编号 | 规则 |
|------|------|
| FR-200-1 | 图片格式支持：JPG、PNG、HEIC |
| FR-200-2 | 单张图片最大：20MB |
| FR-200-3 | OCR 识别仅承诺印刷体准确率（试卷、练习册等印刷品） |
| FR-200-4 | OCR 识别结果为辅助参考，用户可手动编辑修正 |
| FR-200-5 | 原始图片始终保存，OCR 文字与图片独立存储 |
| FR-200-6 | OCR 识别失败时，提示"识别失败，请手动输入题目内容" |
| FR-200-7 | 裁剪框支持手动拖拽调整四角 |
| FR-200-8 | 一道错题对应一张裁剪图片（如需多张，分多次录入） |
| FR-200-9 | 录入成功后显示 Toast 提示"录入成功，已加入复习计划" |
| FR-200-10 | 离线状态下录入的数据暂存本地，联网后自动同步 |

**OCR 服务规格：**

| 项目 | 规格 |
|------|------|
| 服务提供方 | 第三方 OCR API（百度/腾讯，待选型，MVP单源，V1.1评估主备） |
| 支持类型 | 通用文字识别、数学公式识别 |
| 去手写能力 | 需具备教育场景去手写能力，能分离印刷题目与手写笔迹（选型评估指标） |
| 去手写降级 | 若去手写效果不佳，保留原始图片，OCR结果标注"含手写内容，请核对原图" |
| 印刷体准确率目标 | >= 98%（纯印刷体）；带手写答案试卷去手写后印刷体准确率也需评估 |
| 手写体 | 不承诺准确率，尝试识别但不保证，标记"待确认" |
| 单次调用超时 | 5 秒 |
| 超时/失败处理 | 展示原图，提示手动输入 |

**可编辑字段：**

| 解题过程/笔记 | 自由文字输入，支持分步描述 | 错题详情页 |
| 错因标签 | 可修改粗分类和细分类 | 错题详情页 |
| 知识点标签 | 可增删改 | 错题详情页 |
| 自定义标签 | 可增删改 | 错题详情页 |

**业务规则：**

| FR-201-3 | 解题过程支持分步输入，可标注"出错步骤"（点击标红） |

#### FR-202 错题删除

| 编号 | 规则 |
|------|------|
| FR-202-1 | 删除方式为软删除，数据保留 30 天 |
| FR-202-2 | 删除前弹窗确认："确定删除这道错题吗？30天内可在回收站恢复" |
| FR-202-3 | 删除后从错题列表、复习计划中移除 |

### 5.5 错题消灭

#### FR-500 消灭机制

**功能描述：** 定义错题从"未掌握"到"已消灭"的完整生命周期。

**状态流转：**

```
录入 -> NOT_STARTED（未掌握）
          | 首次复习
          v
      REVIEWING（复习中）<-- 复习后未完全掌握（计数未达3）
          | 连续3次"完全掌握"
          v
      MASTERED（已消灭）
          | 30天后自动复活检测
          v
      复活检测 -> 做对了 -> 回到 MASTERED
               -> 做错了 -> 回到 REVIEWING（计数归零）
```

**业务规则：**

| 编号 | 规则 |
|------|------|
| FR-500-1 | 错题状态枚举：NOT_STARTED（未掌握）、REVIEWING（复习中）、MASTERED（已消灭） |
| FR-500-2 | 消灭条件：连续 3 次自评为"完全掌握"。a) "完全掌握" -> master_count + 1 b) "部分记得" -> master_count 不变 c) "完全不会" -> master_count 归零 |
| FR-500-3 | 消灭触发时：a) 状态变为 MASTERED b) 播放消灭动画 c) 从每日复习列表中移除 |
| FR-500-4 | 复活检测（2026-06-17更新）：a) 已消灭 30 天后进入"复活检测"队列 b) 优先级：按消灭时间（mastered_at）最早的优先 c) 展示原题目，用户自评"还记得"或"忘记了" d) "还记得" -> 继续消灭，下次检测间隔递进（30→60→90天） e) "忘记了" -> 状态变回 REVIEWING，master_count 归零，使用鼓励式文案（如"这道题需要再巩固一下哦！"，不使用"复活"字样） f) 复活检测每日最多 3 道 g) 通过 90 天检测后标记为 PERMANENTLY_MASTERED（永久消灭），不再复活检测 h) 复活检测UI入口：出现在每日复习列表最后，加"复习巩固"标签与正常复习题视觉区分 |
| FR-500-5 | 错题详情页展示当前状态和消灭进度（进度条 + 复习历史时间线） |

### 7.3 枚举值定义

#### 年级枚举

| 枚举值 | 含义 |
|--------|------|
| 31 | 小学三年级 |
| 32 | 小学四年级 |
| 33 | 小学五年级 |
| 34 | 小学六年级 |
| 71 | 初中一年级 |
| 72 | 初中二年级 |
| 73 | 初中三年级 |

#### 错题状态枚举

| 枚举值 | 含义 | 颜色标识 |
|--------|------|---------|
| NOT_STARTED | 未掌握 | 红色 |
| REVIEWING | 复习中 | 黄色 |
| MASTERED | 已消灭 | 绿色 |
| PERMANENTLY_MASTERED | 永久消灭（通过90天复活检测） | 深绿色 |

#### 错因粗分类枚举

| 枚举值 | 含义 | 小学生显示文案 | 适用学段 |
|--------|------|--------------|---------|
| KNOWLEDGE | 知识性错误 | 不会做 | 全部 |
| SKILL | 技能性错误 | 算错了 | 全部 |
| PSYCHOLOGY | 心理性错误 | 粗心了 | 全部 |
| HABIT | 习惯性错误 | 看错了 | 全部 |
| UNKNOWN | 不确定（不计入统计） | 🤷 不确定 | 仅小学 |

#### 自评结果枚举

| 枚举值 | 含义 |
|--------|------|
| MASTERED | 完全掌握 |
| PARTIAL | 部分记得 |
| FAILED | 完全不会 |
