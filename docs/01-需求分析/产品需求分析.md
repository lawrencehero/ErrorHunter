# 错题猎手（ErrorHunter）— 产品需求分析

> 编写人：@PM  
> 日期：2026-06-17  
> 状态：已完成

---

## 一、产品愿景

> 学生化身猎手，主动出击消灭错题——**"消灭错题、巩固知识、掌握方法"**。

---

## 二、目标用户画像

| 角色 | 特征 | 核心诉求 |
|------|------|----------|
| **小学生（3-6年级）** | 自主能力较弱，需要引导和激励，注意力集中时间短 | 错题录入简单、复习像游戏一样有趣 |
| **初中生** | 有一定自主学习能力，科目增多，考试压力大 | 高效归档、精准分析薄弱点、科学安排复习 |
| **家长** | 关注孩子学习情况，但缺乏专业辅导能力 | 了解孩子学习状况、看到进步、辅助监督 |
| **老师**（延伸角色） | 关注班级共性错题，因材施教 | 查看学生错题分布、布置针对性练习 |

---

## 三、核心痛点分析

| 痛点 | 表现 |
|------|------|
| **错题归档难** | 手抄费时费力；卷子丢了错题就没了；各科错题分散难以统一管理 |
| **分析不到位** | 不知道错在哪里；同类错误反复犯；找不到知识薄弱点 |
| **复习不科学** | 没有复习计划；会的反复看，不会的总不看；考前不知道看什么 |
| **坚持不下来** | 过程枯燥；没有成就感；家长不知道怎么帮 |

---

## 四、产品核心闭环

```
采集错题（拍照/手动录入/导入）
    ↓
归因分析（错因标签/知识点关联）
    ↓
科学复习（艾宾浩斯/间隔复习）
    ↓
消灭错题（掌握标记/同类题巩固）
    ↓
学情报告（数据可视化/成长轨迹）
```

---

## 五、功能模块拆解

### 模块一：错题采集 📸

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| **拍照录入** | 拍照自动识别题目文字（OCR），支持手写体和印刷体 | P0 |
| **图片裁剪** | 智能识别题目边界，自动裁剪单道题 | P0 |
| **手动录入** | 支持文字输入，公式编辑器（数学公式） | P1 |
| **语音录入** | 学生口述题目，语音转文字（低龄友好） | P2 |
| **批量导入** | 支持从试卷照片批量识别和拆分多道错题 | P2 |
| **错题本导入** | 拍照导入整页错题本，AI自动拆分 | P2 |

### 模块二：归因分析 🔍

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| **错因标签** | 预设错因分类，学生/家长选择标签 | P0 |
| **知识点关联** | 每道错题关联到具体知识点（按课标体系） | P0 |
| **AI 错因分析** | AI 根据题目和错误答案分析可能原因 | P1 |
| **解题步骤标注** | 标注在哪一步出错 | P1 |
| **错题举一反三** | AI推荐同知识点的类似题目进行巩固 | P1 |

**错因标签体系：**

```
错因分类
├── 🧠 知识性错误
│   ├── 概念理解不清
│   ├── 公式/定理记错
│   ├── 知识点混淆
│   └── 前置知识缺失
├── ✍️ 技能性错误
│   ├── 计算错误
│   ├── 审题不清
│   ├── 解题方法不当
│   ├── 步骤遗漏
│   └── 单位/格式错误
├── 😰 心理性错误
│   ├── 粗心大意
│   ├── 紧张失误
│   └── 时间不够
└── 📖 习惯性错误
    ├── 书写潦草导致看错
    ├── 不检查
    └── 答题不规范
```

### 模块三：科学复习 📅

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| **艾宾浩斯复习计划** | 根据遗忘曲线自动安排复习时间 | P0 |
| **每日复习任务** | 每天推送待复习错题清单 | P0 |
| **复习提醒** | 定时推送复习通知（可自定义时间） | P0 |
| **遮挡重做** | 遮住答案，让学生重新做题 | P0 |
| **掌握度评估** | 每次复习后自评掌握程度 | P0 |
| **间隔递增复习** | 根据掌握度动态调整复习间隔 | P1 |
| **考前冲刺模式** | 考前按知识点/错因生成专项复习卷 | P1 |
| **错题组卷** | 将错题和同类题组成练习卷打印 | P2 |

### 模块四：消灭错题 ✅

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| **掌握标记** | 连续N次复习正确后自动标记"已消灭" | P0 |
| **错题状态管理** | 未掌握/复习中/已消灭 三种状态 | P0 |
| **消灭动画** | 消灭错题时的激励动画效果 | P1 |
| **错题复活** | 已消灭的错题一段时间后可重新激活复习 | P2 |

### 模块五：学情报告 📊

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| **错题统计总览** | 各科目错题数量、消灭进度 | P0 |
| **错因分布图** | 饼图展示各类错因占比 | P0 |
| **知识点热力图** | 按知识点展示掌握情况（红/黄/绿） | P1 |
| **学习趋势** | 折线图展示每周新增/消灭错题数 | P1 |
| **薄弱知识点TOP** | 列出最薄弱的知识点排行 | P1 |
| **家长周报** | 每周推送给家长的学习报告 | P1 |
| **成长轨迹** | 长期数据记录，展示进步历程 | P2 |

### 模块六：激励体系 🏆

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| **经验值与等级** | 录入/复习/消灭错题获得经验值 | P1 |
| **成就徽章** | 连续打卡、消灭100题等里程碑徽章 | P1 |
| **消灭排行** | 本周/本月消灭错题排行（可选参与） | P2 |
| **错题消灭日历** | 日历打卡视图，直观展示坚持天数 | P1 |
| **宠物/花园养成** | 消灭错题喂养宠物/种花（低龄激励） | P2 |

## 六、学科支持规划

| 阶段 | 支持科目 | 特殊需求 |
|------|----------|----------|
| **一期** | 数学（小学+初中） | 公式编辑器、计算步骤标注 |
| **二期** | +语文、英语 | 语文阅读理解错题、英语语法错题的特殊模板 |
| **三期** | +物理、化学（初中） | 化学方程式、物理公式支持 |

---

## 七、非功能性需求

| 维度 | 要求 |
|------|------|
| **性能** | 拍照到识别完成 < 3秒；APP启动 < 2秒 |
| **OCR准确率** | 印刷体 > 98%，手写体 > 90% |
| **安全性** | 学生隐私保护（COPPA合规）；数据加密存储 |
| **离线能力** | 基础录入和复习支持离线，联网后同步 |
| **多端支持** | 手机端为主（iOS + Android），平板适配，家长端可为微信小程序 |
| **易用性** | 小学生可独立完成录入和复习（不超过3步操作） |
