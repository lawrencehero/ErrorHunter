**编写人**：张明（产品经理）

**版本**：V1.0

---

## 一、调研背景与目的

错题猎手定位为面向小学3年级至初中学生的**错题全生命周期管理工具**，核心价值主张为"采集→归因→复习→消灭"。本次调研旨在：

1. 摸清中国境内错题管理类APP的竞争格局
2. 对标TOP竞品的核心功能、商业模式和用户口碑
3. 发现差异化机会，为V1.0 MVP及后续版本的产品策略提供依据

---

## 二、竞品选择

根据市场调研，将竞品分为**三大梯队**：

| 梯队 | 代表产品 | 选择理由 |
|------|---------|---------|
| **第一梯队：独立错题本APP** | 橙果错题本、错题Plus、巧学错题本 | 与我们产品定位最直接重叠 |
| **第二梯队：平台型产品（内置错题功能）** | 作业帮、小猿AI | 拥有亿级用户基数，错题本是标配功能 |
| **第三梯队：新兴AI学习工具** | 知微AI | 2026年口碑最好的AI错题分析工具 |

本次重点调研**第一梯队的3款独立错题本APP**（直接竞品），辅以第二、三梯队参考。

## 五、竞品"没做好"的地方 —— 我们的机会窗口 🔥

这是本次调研最重要的结论。通过对比，竞品存在**四个系统性缺口**：

### 缺口1：❌ 没有真正的"错因归因"体系

| 竞品现状 | 我们的机会 |
|---------|-----------|
| 橙果：仅基础分类标签 | 错题猎手：二级错因分类体系（知识性/技能性/心理性/习惯性） |
| 错题Plus：知识点标签匹配 | 错题猎手：不仅知道"错在哪"，更要知道"为什么错" |
| 巧学：简单统计 | 错题猎手：错因分布饼图 + 趋势分析 |

> **用户价值**：家长和孩子最大的痛点不是"记录错题"，而是"搞清楚为什么错"。这是从**记录工具**升级为**诊断工具**的关键。

### 缺口2：❌ 没有科学的复习调度引擎

| 竞品现状 | 我们的机会 |
|---------|-----------|
| 全部竞品均无间隔复习机制 | 错题猎手：艾宾浩斯遗忘曲线5轮复习引擎 |
| 复习完全靠用户自觉 | 错题猎手：每日推送复习任务 + 自适应间距 |
| 无复习完成度追踪 | 错题猎手：复习完成率追踪 + 掌握度自评 |

> **用户价值**：这是竞品集体缺失的**最大空白**。错题记录了但不复习 = 白记录。我们的复习引擎解决了"记了就忘"这个根本矛盾。

### 缺口3：❌ 没有错题"消灭"闭环

| 竞品现状 | 我们的机会 |
|---------|-----------|
| 错题只有"有/无"两个状态 | 错题猎手：三态生命周期（未开始→复习中→已掌握） |
| 无掌握判定标准 | 错题猎手：连续3次"完全掌握"才算消灭 |
| 无复活机制 | 错题猎手：已掌握错题30天后复活检测 |
| 无消灭成就感 | 错题猎手：消灭动画 + 庆祝特效 |

> **用户价值**：让错题管理变成一个**有终点的游戏**，而不是无尽的记录。"消灭"这个动作给孩子明确的成就反馈。

### 缺口4：❌ 没有激励体系，坚持全靠意志力

| 竞品现状 | 我们的机会 |
|---------|-----------|
| 全部竞品无任何游戏化设计 | 错题猎手：经验值 + 等级 + 成就徽章 |
| 无连续打卡激励 | 错题猎手：连续打卡日历 + 醒目的连续天数 |
| 无正反馈循环 | 错题猎手：消灭错题 → 获得经验 → 升级 → 更多动力 |

> **用户价值**：目标用户是3-9年级学生，自驱力有限。激励体系是让产品从"家长要求用"变成"孩子主动想用"的关键杠杆。

## 七、行业趋势与战略判断

### 7.1 2026年行业大势

| 趋势 | 影响 |
|------|------|
| **AI大模型深度融入** | 从"搜题给答案"升级为"过程讲解+错因诊断"，知微AI等新玩家验证了这个方向 |
| **平台型产品挤压独立APP** | 作业帮（MAU 8640万）、小猿AI（MAU 2207万）内置错题本功能，独立APP面临被整合风险 |
| **双减后学习机市场逆势增长** | 教育智能硬件市场2026年预计691亿元，错题管理是核心卖点 |
| **GenAI+教育渗透率K12仅10-15%** | 增量空间巨大，先占者有红利 |

### 7.2 战略判断

> **独立错题本APP的窗口期正在收窄。** 如果不做出"平台做不到"的差异化功能，2-3年内将被作业帮、小猿AI等平台型产品碾压。

**我们的生存空间在于**：
1. ✅ **科学复习引擎** — 平台型产品做不深，因为他们的商业模式是"搜题→广告/课程"，不是"管理错题→消灭错题"
2. ✅ **错因归因体系** — AI赋能的二级归因是技术壁垒
3. ✅ **激励体系 + 游戏化** — 面向小学生的游戏化设计，大平台不会为这个细分场景投入
4. ✅ **离线优先架构** — 很多目标用户（三四线城市家庭）网络条件有限

| 5 | 设计V1.0的用户增长策略（对标橙果的口碑传播路径） | 产品 | V1.0上线前2周 |

---

## 九、结论

**一句话总结**：当前错题本APP市场的竞品普遍停留在**"错题记录工具"**层面，没有一款产品真正做到了**"错题消灭系统"**。错题猎手通过"归因分析 + 科学复习 + 消灭闭环 + 游戏激励"四位一体的差异化设计，有机会在这个细分赛道建立独特价值。

**最大的风险是时间**——作业帮、小猿AI等平台型产品一旦补齐"复习调度"和"错因分析"功能，我们的窗口期将迅速收窄。建议加速MVP上线，用**3个月内**抢占"科学错题管理"的用户心智。
